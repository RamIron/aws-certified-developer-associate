# 26.5 - AWS CDK - Unit Testing

**Status:** ✅ Completed

## Key Concepts

### 1. Testing in CDK
- Because CDK uses real code, you can test it like any normal code
- Uses **CDK Assertions Module** — works with Jest (JavaScript) and Pytest (Python)
- Tests verify that the synthesized CloudFormation template contains what you expect

### 2. Two Types of Tests

#### Fine-Grained Assertions (most common)
- Test specific resources have specific properties
- Example: verify Lambda has correct handler and runtime
- Example: verify SNS topic has exactly one subscription

#### Snapshot Tests
- Test the entire CloudFormation template against a previously stored baseline
- Catch unexpected changes — if something changes, the snapshot fails
- Example: verify DynamoDB table still has expected properties

### 3. Two Ways to Load the Template for Testing

| Method | When to use |
|---|---|
| `Template.fromStack(MyStack)` | Stack is defined in CDK — import and test directly |
| `Template.fromString(myString)` | Template lives outside CDK (raw CF template) — import as string |

Both are exam-relevant — know the difference.

### 4. Example Test (JavaScript/Jest)
```javascript
const template = Template.fromStack(MyStack);

// Fine-grained assertion
template.hasResourceProperties('AWS::Lambda::Function', {
  Handler: 'index.handler',
  Runtime: 'nodejs14.x',
});

// Count assertion
template.resourceCountIs('AWS::SNS::Subscription', 1);
```

## Exam Tips
- CDK tests use the **CDK Assertions Module** (Jest or Pytest)
- **Fine-grained assertions** = test specific resource properties (most common)
- **Snapshot tests** = compare full template against stored baseline
- `Template.fromStack()` = CDK stack | `Template.fromString()` = external CF template
