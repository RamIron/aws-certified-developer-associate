# 26.1 - AWS CDK - Overview

**Status:** ✅ Completed

## Key Concepts

### 1. What is CDK?
- Cloud Development Kit — define cloud infrastructure using a **real programming language**
- Supported languages: TypeScript, JavaScript, Python, Java, .NET
- Compiles/synthesizes into a CloudFormation template (JSON or YAML)
- Typesafe: if the code doesn't compile → no template generated → catches errors early
- Allows deploying **infrastructure + application runtime code together** (great for Lambda, ECS/EKS)

### 2. CDK Constructs
- High-level reusable components that generate multiple underlying resources
- Example (TypeScript):
  ```typescript
  const vpc = new ec2.Vpc(this, 'MyVpc', { maxAzs: 3 });
  const cluster = new ecs.Cluster(this, 'MyCluster', { vpc });
  new ecs_patterns.ApplicationLoadBalancedFargateService(this, 'MyFargate', {
    cluster,
    cpu: 512,
    desiredCount: 6,
    taskImageOptions: { image: ecs.ContainerImage.fromRegistry('amazon/amazon-ecs-sample') },
    memoryLimitMiB: 2048,
    publicLoadBalancer: true,
  });
  ```

### 3. CDK Flow
```
CDK code (TypeScript/Python/Java/.NET)
         │
         │  cdk synth
         ▼
CloudFormation Template (JSON/YAML)
         │
         │  cdk deploy
         ▼
    AWS Resources
```

### 4. CDK vs SAM

| | SAM | CDK |
|---|---|---|
| Focus | Serverless (Lambda-first) | All AWS services (superset of CloudFormation) |
| Template format | Declarative YAML/JSON | Programming language (TS, Python, Java, .NET) |
| Typesafe | No | Yes |
| Backend | CloudFormation | CloudFormation |
| Best for | Quick Lambda/serverless apps | Complex infra, any AWS service |

### 5. CDK + SAM Together
- `cdk synth` → generates CloudFormation template
- Then use `sam local invoke` pointing at that template to test Lambda locally:
  ```bash
  cdk synth
  sam local invoke -t cdk.out/MyStack.template.json MyFunction
  ```

## Exam Tips
- CDK generates CloudFormation under the hood — same backend, better DX
- CDK supports ALL AWS services; SAM is focused on serverless
- Typesafe: code that doesn't compile = no CloudFormation template generated
- `cdk synth` = synthesize CDK into CloudFormation template
- CDK + SAM: use SAM CLI to test CDK-generated Lambda functions locally
