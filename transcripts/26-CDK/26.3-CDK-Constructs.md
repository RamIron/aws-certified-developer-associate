# 26.3 - AWS CDK - Constructs

**Status:** ✅ Completed

## Key Concepts

### 1. What are Constructs?
- Components that encapsulate everything CDK needs to create CloudFormation resources
- Can be a single resource (e.g. S3 bucket) or multiple related resources (e.g. SQS queue + Lambda worker)
- Come from the **Construct Library** (included in CDK, covers every AWS resource)
- Also available from **Construct Hub** — third-party and open-source community constructs

### 2. Three Levels of Constructs

#### Level 1 (L1) — CFN Resources
- Direct mapping to CloudFormation resources
- **Identifier:** always starts with `Cfn` (e.g. `CfnBucket`, `CfnQueue`)
- Requires all CloudFormation resource properties — no defaults
- Use case: migrating existing CloudFormation templates to CDK one resource at a time

```typescript
new s3.CfnBucket(this, 'MyBucket', {
  bucketName: 'my-bucket',
  // must specify all required CF properties
});
```

#### Level 2 (L2) — AWS Resources (Higher Level)
- Same AWS resources but with **intent-based API**, convenient defaults and boilerplate
- Does NOT start with `Cfn`
- Adds helper methods: `bucket.addLifeCycleRule()`, `bucket.grantRead()`, etc.
- Use case: most common CDK development

```typescript
const bucket = new s3.Bucket(this, 'MyBucket', {
  versioned: true,
  encryption: s3.BucketEncryption.KMS,
});
const url = bucket.urlForObject('my-key'); // extra method
```

#### Level 3 (L3) — Patterns
- Represent **multiple related resources** working together
- Highest abstraction — fills in all the wiring automatically
- Examples:
  - `LambdaRestApi` → API Gateway + Lambda integration wired together
  - `ApplicationLoadBalancedFargateService` → ALB + Fargate + target groups + security groups + listeners

```typescript
// Creates API GW + Lambda fully configured
const api = new apigateway.LambdaRestApi(this, 'MyApi', {
  handler: myFunction,
});
```

### Summary Table
| Level | Name | Starts with | What it does |
|---|---|---|---|
| L1 | CFN Resources | `Cfn` | 1:1 CloudFormation mapping, all properties required |
| L2 | AWS Resources | No `Cfn` | Higher-level, defaults + helper methods |
| L3 | Patterns | N/A | Multiple resources combined, complete common tasks |

## Exam Tips
- L1 = starts with `Cfn`, requires all CF properties — lowest level
- L2 = no `Cfn` prefix, adds convenient defaults and methods — most common
- L3 = Patterns, combines multiple resources into one construct — highest level
- Construct Hub has community/third-party constructs beyond the built-in library
