# 26.4 - AWS CDK - Commands & Bootstrapping

**Status:** ✅ Completed

## Key Concepts

### 1. CDK CLI Commands
| Command | What it does |
|---|---|
| `npm install -g aws-cdk-lib` | Install CDK CLI and libraries |
| `cdk init` | Initialize a new CDK app from a template (choose language: Python, JS, TS, Java, .NET) |
| `cdk synth` | Synthesize CDK code → CloudFormation template (prints to stdout) |
| `cdk bootstrap` | One-time setup per account/region — provisions CDKToolkit stack |
| `cdk deploy` | Deploy the CDK stack to AWS via CloudFormation |
| `cdk diff` | Show difference between local CDK changes and what's currently deployed |
| `cdk destroy` | Destroy the deployed CloudFormation stack |

### 2. CDK Bootstrapping
- **What it is:** Provisioning the prerequisites CDK needs before deploying to an AWS environment
- **Environment = account + region combination**
- Creates a CloudFormation stack called **CDKToolkit** containing:
  - An S3 bucket (stores synthesized templates and assets)
  - IAM roles (needed for deployments)
- Must be done **once per account/region**

### 3. Bootstrap Command
```bash
cdk bootstrap aws://<account_id>/<region>
# e.g.
cdk bootstrap aws://123456789012/us-east-1
```

### 4. What happens without bootstrapping
If you try to deploy without bootstrapping:
```
Error: Policy contains a statement with one or more invalid principals
```
This means the IAM role created by CDKToolkit is missing.

## Exam Tips
- `cdk bootstrap` = one-time setup per account/region, creates CDKToolkit CF stack
- Missing bootstrap → "invalid principal" error on deploy
- `cdk diff` = shows what will change before deploying (like a dry-run)
- Environment in CDK = account + region
