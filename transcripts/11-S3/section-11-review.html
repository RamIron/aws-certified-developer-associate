1 — S3 Basics1 — Conceptos Básicos de S3
Buckets, Objects & KeysBuckets, Objetos y Claves

Amazon S3 is object storage that scales infinitely. It is one of AWS's core building blocks — used for backups, static hosting, data lakes, and application storage.Amazon S3 es almacenamiento de objetos que escala infinitamente. Es uno de los bloques de construcción principales de AWS — utilizado para copias de seguridad, alojamiento estático, lagos de datos y almacenamiento de aplicaciones.

BucketsBuckets
  • Top-level container for objects (like a "directory")Contenedor de nivel superior para objetos (como un "directorio")
  • Name must be globally unique across ALL accounts and ALL regionsEl nombre debe ser globalmente único en TODAS las cuentas y TODAS las regiones
  • Bucket itself is a region-level resource (data lives in one region)El bucket en sí es un recurso a nivel de región (los datos viven en una región)
  • Naming: 3–63 chars, lowercase letters, numbers, hyphens — no uppercase, no underscoresNomenclatura: 3–63 caracteres, letras minúsculas, números, guiones — sin mayúsculas, sin guiones bajos
  • Max 100 buckets per account (soft limit)Máx 100 buckets por cuenta (límite suave)
Objects & KeysObjetos y Claves
  • Files stored in buckets are called objectsLos archivos almacenados en buckets se llaman objetos
  • Object key = full path e.g., photos/vacation/beach.jpgClave de objeto = ruta completa p.ej., photos/vacation/beach.jpg
  • Key = prefix (photos/vacation/) + object name (beach.jpg)Clave = prefijo (photos/vacation/) + nombre de objeto (beach.jpg)
  • S3 has NO real directories — the / is just part of the key nameS3 NO tiene directorios reales — el / es solo parte del nombre de la clave
  • Max object size: 5 TBTamaño máximo de objeto: 5 TB
  • Multi-part upload required for files > 5 GB, recommended > 100 MBCarga multiparte requerida para archivos > 5 GB, recomendada > 100 MB
Common confusion on the exam: S3 bucket names are globally unique (across all AWS accounts), but buckets are region-level resources. The S3 console shows all buckets globally, which tricks people. Your data actually lives in the region you selected when creating the bucket.Confusión común en el examen: Los nombres de bucket de S3 son globalmente únicos (en todas las cuentas de AWS), pero los buckets son recursos a nivel de región. La consola de S3 muestra todos los buckets globalmente, lo que engaña a la gente. Sus datos realmente viven en la región que seleccionó al crear el bucket.
2 — S3 Security & Access Control2 — Seguridad de S3 y Control de Acceso
Two Axes of Access ControlDos Ejes de Control de Acceso

Access to S3 objects is granted when an IAM permission OR a resource-based policy allows it, AND there is no explicit deny.El acceso a objetos de S3 se otorga cuando un permiso de IAM O una política basada en recursos lo permite, Y no hay una negación explícita.

IAM User accessAcceso de Usuario IAM
Attach an IAM policy to the user/group granting s3:GetObject etc. Works within the same account. No bucket policy needed.Adjunta una política de IAM al usuario/grupo otorgando s3:GetObject etc. Funciona dentro de la misma cuenta. No se necesita política de bucket.

EC2 instance accessAcceso de instancia EC2

NUNCA almacenes credenciales de AWS en la instancia. El SDK/CLI en EC2 usa automáticamente el rol a través del servicio de metadatos.
PUB
Public internet accessAcceso a Internet Público
Bucket Policy with Principal: "*". Block Public Access setting must be disabled first. Use for static website hosting or public file distribution.Política de Bucket con Principal: "*". La configuración de Bloquear acceso público debe deshabilitarse primero. Úsalo para alojamiento de sitios web estáticos o distribución de archivos públicos.
XAC
Cross-account accessAcceso entre cuentas
Bucket Policy specifying the external account's IAM principal. No IAM policy change needed on your side once bucket policy is set.Política de Bucket especificando el principal de IAM de la cuenta externa. No se necesita cambio de política de IAM de tu lado una vez que se configure la política de bucket.
Block Public Access is an extra safety layer. It overrides bucket policies and ACLs — even if your bucket policy says public, Block Public Access will still block it. Enable at the account level to prevent any bucket in the account from becoming public.Bloquear acceso público es una capa de seguridad adicional. Anula las políticas de bucket y las ACLs — incluso si tu política de bucket dice público, Bloquear acceso público aún lo bloqueará. Habilítalo a nivel de cuenta para evitar que cualquier bucket en la cuenta se haga público.

How to EnableCómo Habilitar
  • Enable "Static website hosting" in bucket PropertiesHabilita "Alojamiento de sitio web estático" en Propiedades del bucket
  • Specify index document (e.g., index.html)Especifica documento índice (p.ej., index.html)
  • Optionally specify error document (e.g., error.html)Opcionalmente especifica documento de error (p.ej., error.html)
  • S3 generates a website endpoint URLS3 genera una URL de punto final del sitio web
  • Bucket policy must allow public s3:GetObjectLa política de bucket debe permitir s3:GetObject público
  • Block Public Access must be DISABLEDBloquear acceso público debe estar DESHABILITADO
Key Facts for the ExamHechos Clave para el Examen
  • 403 Forbidden = bucket policy is not allowing public reads403 Prohibido = la política de bucket no permite lecturas públicas
  • S3 website URL format: bucket.s3-website.region.amazonaws.comFormato de URL del sitio web S3: bucket.s3-website.region.amazonaws.com
  • Valid as a Route 53 Alias target (no additional cost)Válido como destino de Alias de Route 53 (sin costo adicional)
  • Does NOT support HTTPS natively — use CloudFront in front for HTTPSNO soporta HTTPS nativamente — usa CloudFront al frente para HTTPS
  • Only supports GET and HEAD requestsSolo soporta solicitudes GET y HEAD
Route 53 + S3 website: Create an Alias record pointing to the S3 website endpoint. The bucket name MUST match the domain name exactly (e.g., bucket www.example.com for domain www.example.com).Route 53 + sitio web S3: Crea un registro de Alias que apunte al punto final del sitio web de S3. El nombre del bucket DEBE coincidir exactamente con el nombre de dominio (p.ej., bucket www.example.com para dominio www.example.com).
4 — S3 Versioning4 — Versionado de S3
Protecting Objects from Accidental Deletion & OverwritesProtegiendo Objetos de Eliminación Accidental y Sobrescrituras

When versioning is enabled, every upload to the same key creates a new version instead of overwriting. Each version gets a unique Version ID.Cuando el versionado está habilitado, cada carga a la misma clave crea una nueva versión en lugar de sobrescribir. Cada versión obtiene un ID de versión único.

Versioning BehaviorComportamiento del Versionado
  • Enabled at the bucket levelHabilitado a nivel de bucket
  • Once enabled, cannot be fully disabled — only suspendedUna vez habilitado, no se puede deshabilitar completamente — solo suspenderse
  • Suspending does NOT delete existing versionsSuspender NO elimina las versiones existentes
  • Files uploaded before enabling versioning have version = nullLos archivos cargados antes de habilitar el versionado tienen versión = null
  • Protects against accidental overwrites and deletesProtege contra sobrescrituras y eliminaciones accidentales
Delete BehaviorComportamiento de Eliminación
  • Delete without version ID → adds a delete marker (object appears gone but is recoverable — delete the marker)Eliminar sin ID de versión → agrega un marcador de eliminación (el objeto aparece eliminado pero es recuperable — elimina el marcador)
  • Delete with specific version ID → permanent, irreversible deletion of that versionEliminar con ID de versión específico → eliminación permanente e irreversible de esa versión
  • Restoring: delete the delete marker to un-delete an objectRestauración: elimina el marcador de eliminación para deshacer la eliminación de un objeto

Cost implication: Every version is stored and billed. Use Lifecycle Policies to automatically expire old versions (e.g., delete versions older than 90 days) to avoid unbounded storage costs.Implicación de costo: Cada versión se almacena y se factura. Usa Políticas de ciclo de vida para expirar automáticamente versiones antiguas (p.ej., eliminar versiones más antiguas que 90 días) para evitar costos de almacenamiento ilimitados.
