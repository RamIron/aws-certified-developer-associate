# 22.11 - DynamoDB PartiQL

> Core PartiQL concepts already covered in 22.6. This lesson is a hands-on demo of the console editor.

## New Info

### Querying Indexes with PartiQL
- You can query a GSI or LSI directly using PartiQL syntax:
  ```sql
  SELECT * FROM demo_indexes.game_id_index
  WHERE game_id = '456'
  ```
- The index name is appended to the table name with a dot

### Console PartiQL Editor Features
- Auto-generates statements when you click "Scan table" or "Query table" on a table/index
- Results viewable as table or JSON (useful for seeing raw API response format)
- Results can be downloaded as CSV
- Supports Batch operations (multiple statements in one run)

### PartiQL Supports Batch Operations
- Can run multiple INSERT / UPDATE / DELETE statements in a single batch call
- Same limits as BatchWriteItem apply under the hood
