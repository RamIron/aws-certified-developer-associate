# 22.7 - DynamoDB Basic APIs - Hands On

## New Info

### Console Scan Filter vs API FilterExpression
- The **AWS Console's Scan filter** is applied **client-side** (in the browser) — DynamoDB returns all items and the browser filters the display
- The **API's `FilterExpression`** is applied **server-side** by DynamoDB — but still after reading all items, so RCU cost is the same
- These are two different things: console filter = UI convenience only; `FilterExpression` = real API parameter sent to DynamoDB

### Console behavior reminder
- "Create Item" in console → PutItem
- "Edit" on an item → UpdateItem
- Clicking on an item row → GetItem
- "Actions → Delete Items" → BatchWriteItem (delete)
- Dropping the table → DeleteTable (always preferred over Scan + delete)
