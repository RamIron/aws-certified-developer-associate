En la práctica combinás la velocidad del modelo clave-valor con la flexibilidad de guardar documentos ricos y sin esquema fijo dentro de cada ítem.

Add a version attribute to each item. Write with condition version = <version you read>. If someone else modified it first → version mismatch → ConditionalCheckFailedException → re-read and retry.Agregá un atributo version a cada ítem. Step 1 — Initial state
{ user_id: "u1", name: "Bob", version: 1 }
Step 2 — Client 1 writes first

→ must re-read (version=2) and retry

Pessimistic: bloqueás el registro mientras trabajás para que nadie más pueda tocarlo (como SELECT FOR UPDATE en SQL) — no soportado.

Los índices secundarios te permiten consultar por otros atributos. Un LSI mantiene el mismo partition key pero agrega un sort key alternativo. Un GSI define un PK+SK completamente nuevo, creando una vista distinta de la tabla.

Formulas & CapacityFórmulas y Capacidad

RCU strongly consistent→reads × ceil(KB / 4)
RCU eventually consistent→(reads / 2) × ceil(KB / 4)
RCU transactional→(reads × 2) × ceil(KB / 4)
Transactional cost→Always 2× WCU and 2× RCU
On-demand vs Provisioned→~2.5× more expensive. Switch once per 24h.
ProvisionedThroughputExceededException→Exponential backoff (SDK built-in)

APIs

GetItem→Returns exactly 0 or 1 item only
