# 22.10 - DynamoDB Indexes (GSI + LSI) - Hands On

> Hands-on walkthrough confirming concepts from 22.9. No new info.

## Confirmed in Console
- LSI: only available at table creation → "Local" tab disappears after creation
- GSI: can be added at any time from the Indexes tab → requires own RCU/WCU ("Copy from base table" or custom)
- LSI projection options in console: All / Keys only / Include specific attributes
- GSI projection same options
- When querying: can select "Table" or any index from the dropdown → index changes available PK/SK for the query
