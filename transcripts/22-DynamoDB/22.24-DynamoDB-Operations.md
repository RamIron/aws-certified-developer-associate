# 22.24 - DynamoDB Operations

## Key Concepts

### Table Cleanup
| Option | Method | Cost & Speed |
|---|---|---|
| ❌ Slow | Scan + DeleteItem one by one | Expensive — consumes RCU (scan) + WCU (delete) |
| ✅ Fast | Drop table (DeleteTable) + recreate | Fast, cheap — must recreate with same settings |

Already covered in 22.6.

---

### Copying a DynamoDB Table (NEW)

Three options:

| Method | How | Notes |
|---|---|---|
| **AWS Backup** | Backup source table → restore to same or different account | Managed, simple |
| **AWS Glue** | ETL service generates a script to read source + write anywhere | Flexible, good for transformations |
| **Custom code** | Scan + PutItem / BatchWriteItem | Most effort, not recommended when AWS services exist |

---

## Exam Tips
- Table cleanup → always **DeleteTable + recreate** (not Scan + delete)
- Copy table → **AWS Backup** (simple restore) or **AWS Glue** (ETL/transform)
- Custom code (Scan + BatchWriteItem) works but is the hardest option
