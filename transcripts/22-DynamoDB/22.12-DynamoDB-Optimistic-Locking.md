# 22.12 - DynamoDB Optimistic Locking

## Key Concepts

### What is Optimistic Locking?

A strategy to prevent **lost updates** when multiple clients try to modify the same item concurrently.

Built on top of **Conditional Writes** (22.8) — uses a `version` attribute as the condition.

**The pattern:**
1. Each item has a `version` attribute (e.g., starts at 1)
2. When reading an item, you also read its current version
3. When writing, include a condition: `version = <version you read>`
4. If the item was modified by someone else in the meantime → version won't match → `ConditionalCheckFailedException`
5. Client must re-read the latest item and retry if needed

---

### How It Works — Two Clients Example

```
Item in DynamoDB: { user_id: "u1", first_name: "Bob", version: 1 }

Client 1: UpdateItem → name = "John"  IF version = 1
Client 2: UpdateItem → name = "Lisa"  IF version = 1

Both read version = 1 and fire their updates simultaneously.

Client 2 wins the race:
  → DynamoDB updates: { first_name: "Lisa", version: 2 }

Client 1 arrives too late:
  → Condition: version = 1 → but actual version is now 2
  → ConditionalCheckFailedException ❌
  → Client 1 must re-read the item and decide what to do
```

---

### Optimistic vs Pessimistic Locking

| | Optimistic Locking | Pessimistic Locking |
|---|---|---|
| Approach | Assume no conflict, check at write time | Lock the record before reading |
| DynamoDB support | ✅ Yes (via Conditional Writes) | ❌ No native support |
| Performance | Better (no blocking) | Lower (locks block others) |
| On conflict | Reject write, client retries | Wait for lock to release |

DynamoDB only supports Optimistic Locking — there are no locks or transactions that block other readers/writers.

---

## Exam Tips
- Optimistic Locking = version attribute + ConditionExpression (`version = :expected_version`)
- Conflict → `ConditionalCheckFailedException` → client must re-read and retry
- This is the recommended pattern for concurrent writes in DynamoDB
- DynamoDB does NOT support pessimistic locking
