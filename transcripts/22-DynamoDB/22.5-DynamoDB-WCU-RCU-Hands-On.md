## New Info

### Auto Scaling for Provisioned Mode
- Set a **min**, **max**, and **target utilization %** for RCU and WCU
- DynamoDB automatically adjusts capacity within that range based on actual usage
- If the table is idle → scales down to min; if busy → scales up toward max
- Works just like EC2 Auto Scaling Groups, but for DynamoDB throughput
- You still pay for provisioned capacity, but it adapts so you're not over-provisioned

### Capacity Calculator (Console)
- Available when configuring a table in the AWS console
- Input: average item size, reads/sec, writes/sec, consistency type
- Output: estimated RCU, WCU, and monthly cost
- Good tool to practice the exam formulas
