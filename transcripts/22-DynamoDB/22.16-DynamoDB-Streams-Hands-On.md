# 22.16 - DynamoDB Streams - Hands On

> Hands-on walkthrough. Core concepts covered in 22.15.

## New Info

### Event Source Mapping Settings (Lambda trigger)
- **Batch size**: how many stream records Lambda receives per invocation (e.g. 100)
- **Batch window**: optional wait time to accumulate more records before invoking (efficiency)
- **Starting position**: where to start reading from when the trigger is first created
  - `TRIM_HORIZON` = from the beginning of the stream
  - `LATEST` = only new records from this point forward

### IAM Permissions Required
- Lambda's execution role needs **read permissions on DynamoDB** to consume the stream
- Policy: `AmazonDynamoDBReadOnlyAccess` or `AWSLambdaDynamoDBExecutionRole`

### What Stream Records Look Like in Practice
| Operation | NEW_IMAGE | OLD_IMAGE |
|---|---|---|
| INSERT (create) | ✅ present | ❌ none (nothing existed before) |
| MODIFY (update) | ✅ present | ✅ present |
| REMOVE (delete) | ❌ none (nothing after) | ✅ present |

### Stream enabled from
- Table → Exports and Streams tab → DynamoDB stream details → Enable
- Triggers are created and managed from the same tab
