01 — S3 Encryption Methods01 — Métodos de Cifrado de S3
4 Server-Side & Client-Side Encryption Methods4 Métodos de Cifrado del Lado del Servidor y Cliente

S3 supports four distinct encryption approaches. Each has different key ownership, auditability, and performance characteristics. The exam tests which header, which key owner, and when to use each.S3 admite cuatro enfoques de cifrado distintos. Cada uno tiene diferentes características de propiedad de claves, auditoría y rendimiento. El examen prueba qué encabezado, qué propietario de clave y cuándo usar cada uno.

Default Encryption (2023+):Cifrado Predeterminado (2023+): All new S3 buckets and objects use SSE-S3 by default. You can change this to SSE-KMS at bucket level. Bucket policies are evaluated BEFORE default encryption settings are applied. To force HTTPS, use a bucket policy with the aws:SecureTransport condition key.Todos los nuevos buckets de S3 y objetos usan SSE-S3 por defecto. Puedes cambiar esto a SSE-KMS a nivel de bucket. Las políticas de bucket se evalúan ANTES de que se apliquen la configuración de cifrado predeterminado. Para forzar HTTPS, usa una política de bucket con la clave de condición aws:SecureTransport.

KMS Throttling Trap:Trampa de Limitación de KMS: SSE-KMS calls KMS on every upload AND download. KMS quota is 5,000–30,000 requests/second per region. High-throughput S3 buckets can hit this limit. Consider S3 Bucket Keys (reduces KMS API calls by ~99%) to mitigate throttling.SSE-KMS llama a KMS en cada carga Y descarga. La cuota de KMS es 5,000–30,000 solicitudes/segundo por región. Los buckets de S3 de alta velocidad de transferencia pueden alcanzar este límite. Considera S3 Bucket Keys (reduce las llamadas a KMS API en ~99%) para mitigar la limitación.
02 — S3 CORS02 — CORS de S3
Cross-Origin Resource SharingIntercambio de Recursos entre Orígenes

CORS is a web browser security mechanism — it is enforced by the browser, not the server. An "origin" is defined as: scheme + host + port (e.g. https://example.com:443).

How CORS works with S3Cómo funciona CORS con S3
  • Browser on Origin A makes request to S3 bucket (Origin B)El navegador en Origen A hace una solicitud al bucket S3 (Origen B)
  • Browser sends Origin header to S3
  • S3 checks its CORS configurationS3 verifica su configuración CORS
  • S3 responds with Access-Control-Allow-Origin
  • If header matches, browser allows the responseSi el encabezado coincide, el navegador permite la respuesta
Key Rules
  • Configure CORS on the TARGET bucket (the one being called)
  • Allow a specific origin or use * for all origins
  • NOT a server-side security mechanismNO es un mecanismo de seguridad del lado del servidor
  • Pre-flight OPTIONS request sent first for non-simple requestsSe envía primero una solicitud OPTIONS de preflight para solicitudes no simples
  • Common exam scenario: static website on S3 calling another S3 bucketEscenario común en el examen: sitio web estático en S3 llamando a otro bucket S3

03 — MFA Delete03 — Eliminación con MFA
S3 MFA Delete — Extra Deletion ProtectionEliminación con MFA de S3 — Protección Extra contra Eliminación

MFA Delete adds an extra layer of protection against accidental or malicious permanent deletion of versioned objects.La Eliminación con MFA añade una capa extra de protección contra la eliminación permanente accidental o malintencionada de objetos versionados.

Prerequisites & ManagementRequisitos Previos y Gestión
  • Versioning MUST be enabled on the bucketEl versionado DEBE estar habilitado en el bucket
  • Only the ROOT ACCOUNT can enable or disable MFA DeleteSolo la CUENTA RAÍZ puede habilitar o deshabilitar la Eliminación con MFA
  • Only manageable via CLI — not the AWS ConsoleSolo se puede gestionar a través de CLI — no la Consola de AWS
  • Requires a hardware or virtual MFA deviceRequiere un dispositivo MFA de hardware o virtual
When is MFA Required?¿Cuándo se Requiere MFA?
  • MFA RequiredSe Requiere MFA — Permanently delete an object versionEliminar permanentemente una versión de objeto
  • MFA RequiredSe Requiere MFA — Suspend versioning on the bucketSuspender el versionado en el bucket
  • MFA NOT RequiredMFA NO Requerido — Enable versioningHabilitar versionado
  • MFA NOT RequiredMFA NO Requerido — List object versionsListar versiones de objeto
  • MFA NOT RequiredMFA NO Requerido — Add a delete marker (soft delete)Agregar un marcador de eliminación (eliminación suave)
Exam Trap:Trampa de Examen: MFA Delete protects against permanent deletion of specific versions. A regular delete (without version ID) only creates a delete marker — no MFA needed for that. The root account restriction means IAM admins cannot manage MFA Delete without root credentials.La Eliminación con MFA protege contra la eliminación permanente de versiones específicas. Un borrado regular (sin ID de versión) solo crea un marcador de eliminación — no se necesita MFA para eso. La restricción de la cuenta raíz significa que los administradores de IAM no pueden gestionar la Eliminación con MFA sin credenciales de raíz.
04 — S3 Access Logs04 — Registros de Acceso de S3
S3 Server Access LoggingRegistro de Acceso del Servidor S3

S3 Access Logs capture all requests made to a bucket — successful and failed, from any account. Essential for auditing, security analysis, and compliance.Los registros de acceso de S3 capturan todas las solicitudes realizadas a un bucket — exitosas y fallidas, de cualquier cuenta. Esencial para auditoría, análisis de seguridad y cumplimiento.

What Gets LoggedQué se Registra
  • All requests (GET, PUT, DELETE, HEAD)Todas las solicitudes (GET, PUT, DELETE, HEAD)
  • Authorized AND denied requestsSolicitudes autorizadas Y denegadas
  • Requests from any AWS accountSolicitudes de cualquier cuenta de AWS
  • Requester, bucket, key, action, response statusSolicitante, bucket, clave, acción, estado de respuesta
  • Error codes when applicableCódigos de error cuando sea aplicable
Configuration RulesReglas de Configuración
  • Stored in a different S3 bucket (same region)Almacenado en un bucket de S3 diferente (misma región)
  • Analyze with Amazon Athena (SQL queries on log files)Analizar con Amazon Athena (consultas SQL en archivos de registro)
  • Log format is AWS log format (parseable)El formato de registro es formato de registro de AWS (analizable)
  • No realtime — logs delivered within a few hoursSin tiempo real — registros entregados en pocas horas
Infinite Loop Warning — Critical Exam Trap:Advertencia de Bucle Infinito — Trampa de Examen Crítica: NEVER configure the logging target bucket to be the SAME as the monitored bucket. If you do, S3 writes a log entry for every log write, triggering another log write, infinitely. Result: exponential storage growth and a massive, unexpected AWS bill.NUNCA configures el bucket de destino de registro para que sea EL MISMO que el bucket monitoreado. Si lo haces, S3 escribe una entrada de registro por cada escritura de registro, disparando otra escritura de registro, infinitamente. Resultado: crecimiento exponencial del almacenamiento y una factura de AWS masiva e inesperada.

05 — Pre-signed URLs05 — URLs Prefirmadas
S3 Pre-signed URLs — Temporary AccessURLs Prefirmadas de S3 — Acceso Temporal

A pre-signed URL embeds temporary credentials into the URL itself. The URL recipient inherits the permissions of the IAM user or role that generated it.

How It WorksCómo Funciona
  • Generator signs the URL with their AWS credentials + expiryEl generador firma la URL con sus credenciales de AWS + vencimiento
  • Recipient uses URL directly — no AWS account neededEl destinatario usa la URL directamente — no se necesita cuenta de AWS
  • Inherits generator's S3 permissionsHereda los permisos de S3 del generador
  • Works for GET (download) and PUT (upload)Funciona para GET (descargar) y PUT (cargar)
  • URL expires after the configured durationLa URL vence después de la duración configurada
Common Use CasesCasos de Uso Comunes
  • Serve private/premium S3 content to logged-in usersServir contenido de S3 privado/premium a usuarios conectados
  • Allow one-time file download without making bucket publicPermitir descarga de archivo de una sola vez sin hacer el bucket público
  • Allow logged-in user to upload directly to a specific S3 pathPermitir que el usuario conectado cargue directamente en una ruta de S3 específica
  • Temporary media access (e.g. video streaming for paying users)Acceso a medios temporal (p. ej. transmisión de video para usuarios de pago)
Generation MethodMétodo de Generación Max ExpirationVencimiento Máximo NotesNotas
S3 ConsoleConsola de S3 12 hours12 horas Quickest to generate, limited durationMás rápido de generar, duración limitada
AWS CLI / SDK 168 hours (7 days)168 horas (7 días) Use --expires-in flag (seconds)Usar indicador --expires-in (segundos)
Architecture flow:Flujo de Arquitectura: App server generates pre-signed URL using its IAM role → Returns URL to client → Client uses URL directly against S3 → S3 validates signature and expiry → serves object. The app server credentials are never exposed to the client.El servidor de aplicaciones genera la URL Prefirmada usando su rol de IAM → Devuelve la URL al cliente → El cliente usa la URL directamente contra S3 → S3 valida la firma y vencimiento → sirve el objeto. Las credenciales del servidor de aplicaciones nunca se exponen al cliente.
06 — S3 Access Points06 — Puntos de Acceso de S3
S3 Access Points — Simplify Bucket PoliciesPuntos de Acceso de S3 — Simplificar Políticas de Bucket

Access Points solve the "bucket policy is getting too complex" problem. Instead of one massive bucket policy serving many teams, each team or application gets its own Access Point with its own scoped policy.Los Puntos de Acceso resuelven el problema de "la política de bucket se está volviendo demasiado compleja". En lugar de una política de bucket masiva que sirva a muchos equipos, cada equipo o aplicación obtiene su propio Punto de Acceso con su propia política limitada.

Access Point PropertiesPropiedades del Punto de Acceso
  • Each access point has its own unique DNS nameCada punto de acceso tiene su propio nombre DNS único
  • Each access point has its own IAM-like access policyCada punto de acceso tiene su propia política de acceso similar a IAM
  • Policies scoped to specific prefixes (e.g., /finance/)Políticas limitadas a prefijos específicos (p. ej. /finance/)
  • Simplifies management for large multi-tenant bucketsSimplifica la gestión de buckets multitenant grandes
  • Can be scoped to VPC origin (private access only)Puede limitarse al origen de VPC (solo acceso privado)
VPC Origin Access PointsPuntos de Acceso de Origen de VPC
  • Restricts access to traffic from a specific VPCRestringe el acceso al tráfico de una VPC específica
  • Traffic never leaves the AWS networkEl tráfico nunca sale de la red de AWS
  • Requires a VPC Endpoint (Gateway or Interface) for S3Requiere un VPC Endpoint (Gateway o Interface) para S3
  • VPC Endpoint policy must allow access to the Access PointLa política de VPC Endpoint debe permitir el acceso al Punto de Acceso
  • Most secure pattern for internal team accessPatrón más seguro para acceso de equipo interno
