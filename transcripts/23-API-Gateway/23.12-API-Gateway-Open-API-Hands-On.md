# 23.12 - API Gateway Open API - Hands On

**Section:** 23 - AWS Serverless: API Gateway
**Type:** Hands-on (skipped quiz) — key steps noted

---

## What Was Demonstrated

### Import
- Created a new REST API using the **Import** option
- Used the built-in **Example API** (Pet Store) as the OpenAPI definition file
- API Gateway automatically created all resources and methods from the spec

### Export
- Went to an existing API stage (prod)
- Stage Actions → Export
- Options: Swagger or OpenAPI 3, JSON or YAML, with/without API GW extensions, with/without Postman extensions

### SDK Generation
- From the API Gateway console, you can generate client SDKs for:
  Android, JavaScript, iOS, Java, Ruby, and more
- SDK is generated directly from the API definition

---

## Exam Reminder
- Import = create API from OpenAPI spec file
- Export = generate OpenAPI spec from existing API (per stage)
- SDK generation = available directly from API Gateway console
