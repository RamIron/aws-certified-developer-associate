## What This Section Covers

This section completes the serverless stack by introducing **Amazon API Gateway** — the managed service that lets you expose your Lambda functions (and other backends) as a REST API, without managing any servers.

### What You'll Learn

- **API Gateway** — expose Lambda as a REST API
- **Amazon Cognito** — user authentication & authorization
- How these pieces come together to deploy a full serverless API to the cloud

---

## Key Takeaway

API Gateway is the **front door** of your serverless application. It handles routing, auth, throttling, and more — so you never have to run an API server.
