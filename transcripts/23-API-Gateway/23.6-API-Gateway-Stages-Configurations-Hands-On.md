# 23.6 - API Gateway Stages Configurations Hands On

**Section:** 23 - AWS Serverless: API Gateway
**Type:** Hands-on (skipped quiz) — configuration overview

---

## Stage Configuration Options

| Setting | What it does |
|---------|-------------|
| **Cache** | Cache API requests/responses to reduce backend calls |
| **Throttling** | Set rate (requests/sec) and burst limits |
| **Firewall & Client Certificate** | Verify requests actually come from API Gateway |
| **CloudWatch Logs** | Error only / Info / Full request+response (full may expose sensitive data) |
| **Detailed Metrics** | Enable detailed CloudWatch metrics |
| **Custom Access Logging** | Custom log format |
| **X-Ray Tracing** | Full integration with X-Ray for distributed tracing |
| **Stage Variables** | Key-value config per stage |
| **Deployment History** | All past deployments to this stage (enables rollback) |
| **Canary** | Canary deployments (covered in upcoming lesson) |
| **Tags** | Tag the stage itself |

---

## Note
Most of these settings are covered in detail in upcoming lessons (caching, canary, logging, etc.).
