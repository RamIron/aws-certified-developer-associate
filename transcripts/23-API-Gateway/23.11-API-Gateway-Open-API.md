# 23.11 - API Gateway Open API

**Section:** 23 - AWS Serverless: API Gateway

## OpenAPI & API Gateway

OpenAPI (v3.0) is a standard way to define REST APIs as code — in YAML or JSON.

API Gateway has a tight, two-way integration with it:

| Direction | What it does |
|-----------|-------------|
| **Import** OpenAPI → API GW | Automatically creates methods, integrations, responses, and AWS extensions |
| **Export** API GW → OpenAPI | Generates the spec from your existing API (can be used to generate client SDKs) |

### AWS Extensions
OpenAPI specs for API Gateway can include AWS-specific extensions (prefixed with `x-amazon-apigateway-`) to configure integrations, authorizers, etc. directly in the spec file.

## Request Validation

API Gateway can validate incoming requests **before** they reach the backend, using the OpenAPI spec as the schema.

### Why it matters
- Rejects invalid requests with a **400 error** at the gateway level
- Reduces unnecessary calls to the backend
- Shifts validation responsibility to the infrastructure layer

### What can be validated
- Request parameters present in the **URI**
- **Query string** parameters (present and non-blank)
- **Headers** (present and non-blank)
- **Request body** — must adhere to a JSON Schema model defined in the spec

### How to configure
Use the `x-amazon-apigateway-request-validator` extension in the OpenAPI spec.

**Step 1 — Define the validators** (at the top level of the spec):
```json
"x-amazon-apigateway-request-validators": {
  "all": {
    "validateRequestBody": true,
    "validateRequestParameters": true
  },
  "params-only": {
    "validateRequestBody": false,
    "validateRequestParameters": true
  }
}
```

**Step 2 — Apply validators:**
- Apply `params-only` to **all methods** at the API level:
  ```json
  "x-amazon-apigateway-request-validator": "params-only"
  ```
- Override with `all` on a **specific method** (e.g. POST /validation):
  ```json
  "paths": {
    "/validation": {
      "post": {
        "x-amazon-apigateway-request-validator": "all"
      }
    }
  }
  ```

## Exam Tips

- OpenAPI spec = import to create API GW, or export to generate client SDKs
- Spec format: **YAML or JSON**
- Request validation = API GW returns **400** for invalid requests before hitting backend
- Can validate: URI params, query strings, headers, request body (JSON Schema)
- AWS extensions use the `x-amazon-apigateway-` prefix
