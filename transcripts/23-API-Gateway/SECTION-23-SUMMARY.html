API Gateway OverviewVisión General de API Gateway

API Gateway is AWS's fully managed service for creating, publishing, and securing APIs at any scale — with no infrastructure to manage. It acts as the "front door" for backend services: it receives HTTP requests from clients, applies rules (auth, throttling, caching), and forwards them to Lambda, HTTP endpoints, or other AWS services. API Gateway es el servicio totalmente gestionado de AWS para crear, publicar y asegurar APIs a cualquier escala — sin infraestructura que administrar. Actúa como la "puerta de entrada" a los servicios backend: recibe solicitudes HTTP de los clientes, aplica reglas (autenticación, throttling, caché) y las reenvía a Lambda, endpoints HTTP u otros servicios de AWS.

Stages, Deployment & CanaryStages, Deployment y Canary

A Stage is a named snapshot of your API (e.g. dev, prod). Every time you change the API, those changes are not live until you explicitly deploy to a stage. Each stage has its own URL, its own settings (throttling, caching, logging), and its own set of stage variables.Un Stage es una instantánea con nombre de tu API (ej. dev, prod). Cada vez que modificás la API, los cambios no están activos hasta que los deployás explícitamente a un stage. Cada stage tiene su propia URL, su propia configuración (throttling, caché, logs) y su propio conjunto de stage variables.

🚨 Most common confusion: changes are NOT live until you deploy to a stage.Confusión más común: los cambios NO están activos hasta deployar en un stage.

Stage VariablesVariables de Stage

Key-value pairs attached to a stage — like environment variables, but for API Gateway. They let you change what a stage points to without redeploying the API. The classic use case: store the Lambda alias name in a stage variable, so each stage calls a different alias using a single integration ARN.Pares clave-valor adjuntos a un stage — como variables de entorno, pero para API Gateway. Permiten cambiar a qué apunta un stage sin redesplegar la API. El caso de uso clásico: guardar el nombre del alias de Lambda en una variable de stage, para que cada stage llame a un alias distinto usando un único ARN de integración.
