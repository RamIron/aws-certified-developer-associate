## Key Clarification: Stage Variable Syntax

There are **two formats** depending on context:

| Context | Format | Example |
|---------|--------|---------|
| Inside a Lambda ARN (string interpolation) | `${stageVariables.varName}` | `arn:...:function:myFunc:${stageVariables.lambdaAlias}` |
| General reference / mapping templates | `$stageVariables.varName` | `$stageVariables.lambdaAlias` |

When embedding a stage variable inside a string like a Lambda ARN, **curly braces are required**.

---

## Permissions Gotcha ⚠️

When using a stage variable in the Lambda ARN, API Gateway doesn't know which alias you'll use at deploy time. You must **manually grant invoke permissions for each alias** via CLI — one command per alias (DEV, TEST, PROD).

The console will show you the command template but you need to run it once per alias.

---

## Exam Tips

- Stage variable in Lambda ARN = `${stageVariables.varName}` (with curly braces)
- Each Lambda alias needs its own resource-based policy allowing API Gateway to invoke it
- Stage variable name (`lambdaAlias`) is user-defined — not an AWS keyword
