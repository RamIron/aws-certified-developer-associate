## Key Exam Concepts from This Lesson

### Integration Types (5 options in the console)
1. **Lambda Function** — most common
2. **HTTP** — proxy to any HTTP endpoint
3. **Mock** — return a fixed response without hitting a backend
4. **AWS Service** — integrate directly with AWS APIs
5. **VPC Link** — access resources inside a VPC

### API Gateway Timeout ⚠️
- Default timeout: **29 seconds**
- Maximum timeout: **29 seconds** (hard limit — cannot exceed this)
- Lambda can run up to 15 minutes, but API Gateway will cut it off at 29s
- This is a classic exam trap!

### Lambda Proxy Integration
- When enabled, API GW passes the **full request** to Lambda as an event object
- The event includes: `resource`, `path`, `httpMethod`, `headers`, `queryStringParameters`, etc.
- Lambda must return a structured response: `statusCode`, `headers`, `body`

### Stages
- API GW doesn't expose your API until you **Deploy** it to a stage
- Stage name becomes part of the URL: `https://{id}.execute-api.{region}.amazonaws.com/{stage}`
- Example: `/dev/houses`

---

## Exam Tips
- API Gateway timeout = **29 seconds max** (regardless of Lambda timeout)
- Lambda proxy integration = full request/response pass-through
- Must deploy to a stage before the API is publicly accessible
- Mock integration = useful for returning fixed responses without a backend
