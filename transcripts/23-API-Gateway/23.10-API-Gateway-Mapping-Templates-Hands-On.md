# 23.10 - API Gateway Mapping Templates Hands On

**Section:** 23 - AWS Serverless: API Gateway
**Type:** Hands-on (skipped quiz) — key concepts noted

---

## What Was Demonstrated

- Created a Lambda integration **without** proxy mode
- Lambda returns a simple JSON: `{ "example": "hello world" }`
- Added a mapping template on the **integration response** to rename the key
- Result: API Gateway returned `{ "my key": "my value", "renamed key": "hello world" }`

---

## Key Observation: Non-Proxy Lambda Response

Without proxy integration, **Lambda doesn't need to return statusCode/headers/body**. It can just return plain data and API Gateway handles the HTTP response wrapping.

Contrast with Lambda Proxy where Lambda **must** return:
```json
{
  "statusCode": 200,
  "headers": { ... },
  "body": "..."
}
```

---

## VTL Syntax (for reference, not required for exam)

To access a value from the Lambda response inside a mapping template:

```
$input.json('$.example')
```

- `$input` = the JSON received as input
- `$.example` = access the `example` key
