# 23.14 - API Gateway Usage Plans & API Keys

**Section:** 23 - AWS Serverless: API Gateway

---

## Concepts

### Usage Plan
Defines **who** can access your API, **how much**, and **how fast**:
- Links to one or more API stages and methods
- Sets **throttling limits** (requests per second)
- Sets **quota limits** (e.g. 10,000 requests/month)
- Links to API keys to identify and meter clients

### API Keys
- Alphanumeric strings distributed to customers
- Passed by callers in the `x-api-key` request header
- Used to authenticate requests and track usage
- Throttling limits are applied **at the API key level**

---

## Setup Order (important for the exam!)

1. Create one or more APIs, configure methods to **require an API key**, and deploy to stages
2. Generate or import **API keys** to distribute to customers
3. Create a **usage plan** with throttle and quota limits
4. **Associate** API stages and API keys with the usage plan ← easy to forget!

> If you skip step 4, nothing will work.

---

## How Clients Use It

Callers must include the API key in every request:
```
Header: x-api-key: <your-api-key>
```

---

## Exam Tips

- Usage plan = throttle + quota + API key association
- API key passed via `x-api-key` header
- Throttling applied at **API key level**
- Setup order matters — associate stages + keys to the plan **last**
- Quota = total requests allowed in a period (e.g. per month)
- Throttle = requests per second rate limit
