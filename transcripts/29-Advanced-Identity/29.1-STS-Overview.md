# 29.1 - STS Overview

## What is STS?

AWS **Security Token Service (STS)** issues **temporary security credentials** (up to 1 hour) to access AWS resources without creating permanent IAM users or sharing long-term keys.

---

## STS APIs — The 7 You Need to Know

| API | Purpose |
|---|---|
| **AssumeRole** | Assume a role within your account or cross-account |
| **AssumeRoleWithSAML** | Temporary credentials for users logged in with SAML |
| **AssumeRoleWithWebIdentity** | Roles for users logged in with Facebook/Google/OIDC — **deprecated, use Cognito Identity Pools instead** |
| **GetSessionToken** | For MFA — returns Access Key + Secret Key + Session Token |
| **GetFederationToken** | Temporary credentials for a federated user |
| **GetCallerIdentity** | Returns details about who is making the API call (IAM user/role + account number) |
| **DecodeAuthorizationMessage** | Decodes an AWS API denial error message |

### Most important for the exam
- **AssumeRole**
- **GetSessionToken** (MFA)
- **GetCallerIdentity**
- **DecodeAuthorizationMessage**

---

## AssumeRole — How it works

```
User / Application
        │
        │  1. AssumeRole API call
        ▼
      AWS STS
        │
        │  2. Checks IAM permissions
        │
        │  3. Returns temporary credentials
        ▼
  Acts as the role
  (valid 15 min – 1 hour)
```

### Use cases
- **Same-account**: assume a role with specific permissions
- **Cross-account**: create role in target account → write correct permissions on both sides → call AssumeRole → access target resources (e.g. S3 bucket in another account)

## STS with MFA — GetSessionToken

- Use `GetSessionToken` when you have **MFA** on a user or root account
- Returns: **Access Key ID + Secret Access Key + Session Token + Expiry date**
- IAM policy must include condition: `"aws:MultiFactorAuthPresent": "true"`

### Example policy (only allows EC2 stop/terminate if MFA is active)
```json
{
  "Effect": "Allow",
  "Action": ["ec2:StopInstances", "ec2:TerminateInstances"],
  "Resource": "*",
  "Condition": {
    "Bool": {
      "aws:MultiFactorAuthPresent": "true"
    }
  }
}
```
