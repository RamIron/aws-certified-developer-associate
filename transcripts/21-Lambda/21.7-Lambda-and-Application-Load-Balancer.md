# 21.7 - Lambda & Application Load Balancer

> Udemy Lecture #270 · Section 21: AWS Serverless: Lambda

## Key Concepts

### 1. Exposing Lambda via HTTP

Two ways to expose Lambda over HTTP/HTTPS:
- **Application Load Balancer (ALB)** — this lesson
- **API Gateway** — future section

Lambda must be registered in a **target group** for ALB to invoke it.

```
Client → HTTP/HTTPS → ALB → (sync invoke) → Lambda
                       ALB ← response ←────── Lambda
Client ← HTTP ←─────── ALB
```

### 2. HTTP → JSON Conversion (ALB to Lambda)

ALB converts the HTTP request into a **JSON event** for Lambda:

```json
{
  "requestContext": { "elb": { "targetGroupArn": "..." } },
  "httpMethod": "GET",
  "path": "/lambda",
  "queryStringParameters": { "query": "1234ABCD" },
  "headers": { "connection": "keep-alive", "host": "..." },
  "body": "...",
  "isBase64Encoded": false
}
```

Key fields: **query string parameters** (key/value pairs), **headers** (key/value pairs), **body**, and **isBase64Encoded**.

### 3. JSON → HTTP Conversion (Lambda to ALB)

Lambda must return a specific JSON structure that ALB converts back to HTTP:

```json
{
  "statusCode": 200,
  "statusDescription": "200 OK",
  "headers": { "Content-Type": "text/html" },
  "body": "<h1>Hello from Lambda</h1>",
  "isBase64Encoded": false
}
```

### 4. ALB Multi-Value Headers

A setting you enable on the ALB. When the same query parameter or header key appears multiple times:

```
GET /lambda?name=foo&name=bar
```

Without multi-value headers: only one value kept.
With multi-value headers: **both values kept as an array:**

```json
{
  "queryStringParameters": { "name": ["foo", "bar"] }
}
```

Applies to both **query string parameters** and **HTTP headers**.

---

## Exam Tips

- Lambda in ALB target group → ALB invokes Lambda **synchronously**
- ALB converts HTTP → JSON (request) and JSON → HTTP (response)
- Query strings + headers = **key/value pairs** in the JSON event
- Multi-value headers = same key with multiple values → sent as **array**
- Lambda response MUST include: `statusCode`, `headers`, `body`, `isBase64Encoded`
