# 21.5 - Lambda Synchronous Invocations

> Udemy Lecture #268 · Section 21: AWS Serverless: Lambda

## Key Concepts

### 1. What Is Synchronous Invocation?

You call Lambda and **wait for the result**. The response comes back directly to the caller.

```
Client → invoke Lambda → wait... → get response
```

- CLI, SDK, API Gateway, ALB — all synchronous
- **Errors must be handled on the client side** (retry, exponential backoff, etc.)
- Lambda does NOT retry for you in synchronous mode — it's YOUR responsibility

### 2. How It Works with API Gateway

```
Client → API Gateway → Lambda → response → API Gateway → Client
            (proxy)                           (proxy)
```

The client waits the entire time — that's what makes it synchronous.

## Exam Tips

- Synchronous = caller **waits** for the result
- Error handling is **client-side** (retries, exponential backoff)
- Lambda does NOT auto-retry on synchronous invocations
- ALB, API Gateway, CloudFront, CLI, SDK → all synchronous
