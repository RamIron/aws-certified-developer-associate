# 21.14 - Lambda & S3 Event Notifications - Hands On

> Udemy Lecture #277 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### Setup Steps
1. **Create Lambda function** → `lambda-s3`, Python
2. **Create S3 bucket** → `demo-s3-event-stephane` (same region as Lambda!)
3. **S3 → Properties → Event Notifications → Create**
   - Name: `invoke-lambda`
   - Event types: **All object create events**
   - Destination: **Lambda function** → `lambda-s3`

### Resource-Based Policy (auto-created)

Same pattern as ALB and EventBridge — S3 auto-creates a resource-based policy:

```json
{
  "Effect": "Allow",
  "Principal": { "Service": "s3.amazonaws.com" },
  "Action": "lambda:InvokeFunction",
  "Resource": "arn:aws:lambda:...:lambda-s3",
  "Condition": {
    "ArnLike": {
      "AWS:SourceArn": "arn:aws:s3:::demo-s3-event-stephane"
    }
  }
}
```

### S3 Event Payload

After uploading `coffee.jpeg`, CloudWatch Logs shows:

```json
{
  "Records": [{
    "eventSource": "aws:s3",
    "eventName": "ObjectCreated:Put",
    "s3": {
      "bucket": {
        "name": "demo-s3-event-stephane"
      },
      "object": {
        "key": "coffee.jpeg",
        "size": 12345,
        "eTag": "..."
      }
    }
  }]
}
```

Key info in the event: **bucket name**, **object key**, **size**, **eTag** — enough for Lambda to call `s3:GetObject` and process the file.

### Testing
1. Upload file to S3 bucket
2. Lambda → Monitor → View CloudWatch Logs
3. Event shows bucket name, object key, size, etc.

---

## Exam Tips

- S3 → Lambda = **resource-based policy** (auto-created) — same pattern as ALB and EventBridge
- S3 event payload contains `Records[]` array with bucket name and object key
- Lambda can use that info to call `s3:GetObject` to retrieve and process the file
- S3 bucket and Lambda function must be in the **same region**
- Three services that auto-create resource-based policies on Lambda: **ALB, EventBridge, S3**
