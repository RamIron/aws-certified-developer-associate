## Lambda + EFS

- Lambda can mount **EFS (Elastic File System)** if running in a **VPC**
- Mounted to a local directory during initialization
- Requires **EFS Access Points**
- Two limits to watch:
  1. **EFS connection limits** — each Lambda instance = 1 connection to EFS
  2. **Connection burst limits** — many Lambda instances spinning up at once can exceed burst capacity

## Lambda Storage Options Comparison

| Feature | /tmp | Lambda Layers | Amazon S3 | Amazon EFS |
|---------|------|---------------|-----------|------------|
| **Max size** | 10,240 MB | 5 layers, 250 MB total | Elastic | Elastic |
| **Persistence** | Ephemeral | Durable | Durable | Durable |
| **Content** | Dynamic | Static | Dynamic | Dynamic |
| **Storage type** | File System | Archive | Object | File System |
| **Operations** | Any file system op | Immutable | Atomic with Versioning | Any file system op |
| **Pricing** | Included in Lambda | Included in Lambda | Storage + Requests + Data Transfer | Storage + Data Transfer + Throughput |
| **Sharing / Permissions** | Function only | IAM | IAM | IAM + NFS |
| **Data access speed** | **Fastest** | **Fastest** | Fast | Very Fast |
| **Shared across invocations?** | **No** | Yes | Yes | Yes |

---

## Decision Guide

```
  Need temporary scratch space?
  └──► /tmp (fastest, up to 10 GB, ephemeral)

  Need to share static dependencies across functions?
  └──► Lambda Layers (immutable, up to 250 MB)

  Need durable object storage accessible from anywhere?
  └──► S3 (unlimited, API-based)

  Need shared file system across Lambda instances?
  └──► EFS (requires VPC, watch connection limits)
```

---

## Exam Tips

- EFS on Lambda requires: **VPC** + **EFS Access Points**
- Watch for **EFS connection limits** with many concurrent Lambda instances
- **/tmp** = fastest, ephemeral, per-instance, up to 10 GB
- **Lambda Layers** = static/immutable, shared, up to 250 MB total
- **S3** = durable, object-based, unlimited, network speed
- **EFS** = durable, file system, shared across invocations, very fast (NFS)
- Key differentiator: "shared mutable file system" → **EFS**, not /tmp
