# 21.23 - Lambda Environment Variables - Hands On

> Udemy Lecture #286 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### Setup
1. Create Lambda function → `lambda-config-demo`, Python
2. Code uses `os.getenv("ENVIRONMENT_NAME")` to read the env var

```python
import os

def handler(event, context):
    return os.getenv("ENVIRONMENT_NAME")
```

### Adding Environment Variables
1. Configuration → **Environment Variables** → Edit
2. Add key: `ENVIRONMENT_NAME`, value: `dev`
3. Test → returns `"dev"`
4. Change value to `prod` (no code change!) → returns `"prod"`

### Key Takeaway

Same code, different behavior — just by changing the environment variable value. No redeployment needed.
