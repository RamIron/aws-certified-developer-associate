# 21.45 - Lambda Function URL - Hands On

> **Lecture 308** | Section 21: AWS Serverless: Lambda
> Creating and testing a Lambda Function URL in the console

---

## What Was Demonstrated

1. Created `lambda-demo-url` (Python 3.9), returns `{"statusCode": 200, "body": "Hello from Lambda"}`
2. Published **Version 1**, created **DEV alias** pointing to V1
3. On the alias → Function URL → **Create Function URL**
   - AuthType: **NONE** (public access)
   - Resource-based policy **auto-created**: allows anyone to invoke
   - CORS configuration available but not needed for this demo
4. Opened the Function URL in browser → **"Hello from Lambda"** displayed
5. Confirmed: on a specific **version** (V1), Function URL option says: *"You can only add a Function URL to unpublished function versions or an alias"*
6. On `$LATEST`, you CAN also create a Function URL

---

## Key Observations

- Resource-based policy is **auto-created** when using AuthType NONE in console
- Function URL is **permanent** — same URL forever for that alias
- Cannot attach Function URL to specific versions (V1, V2) — only **aliases** or **$LATEST**
- CORS is configurable at creation time (origins, headers, etc.)
