# 21.2 - Serverless Introduction

> Udemy Lecture #265 · Section 21: AWS Serverless: Lambda

## Key Concepts

### 1. What Is Serverless?

- Serverless ≠ "no servers" — it means **you don't manage them**
- You deploy code, AWS handles provisioning, scaling, patching, availability
- Originally meant **FaaS (Function as a Service)** — pioneered by AWS Lambda
- Now includes any service where you don't provision servers

### 2. Serverless Services in AWS

| Service | What It Does |
|---------|-------------|
| **Lambda** | Run code (functions) without servers |
| **DynamoDB** | NoSQL database |
| **Cognito** | User identity / authentication |
| **API Gateway** | REST API front door |
| **S3** | Object storage |
| **SNS / SQS** | Messaging — scales on its own |
| **Kinesis Data Firehose** | Streaming delivery — pay per throughput |
| **Aurora Serverless** | Database that scales on demand |
| **Step Functions** | Orchestrate workflows |
| **Fargate** | Run Docker containers without managing EC2 |

### 3. Reference Architecture

```
                        Users
                       / | \
          Static content  |  Log in
                 /    REST API    \
                /         |        \
         S3 bucket   API Gateway   Cognito
                          |
                        Lambda
                          |
                       DynamoDB
```

## Exam Tips

- "Serverless" on the exam = no server provisioning = Lambda, DynamoDB, API Gateway, Cognito, S3, SQS, SNS, Fargate, etc.
- Fargate = serverless version of ECS (no EC2 management)
- FaaS = Function as a Service = Lambda
