## CodeDeploy + Lambda

CodeDeploy automates the **traffic shift between Lambda alias versions**. Instead of manually adjusting weights, CodeDeploy does it for you over time.

```
  PROD Alias
     │
     │  CodeDeploy shifts X% over time:
     │
     │  Start:  100% V1,   0% V2
     │  ...      90% V1,  10% V2
     │  ...      50% V1,  50% V2
     │  End:      0% V1, 100% V2
```

> Integrated with the **SAM framework** (practiced in SAM section)

---

## Deployment Strategies

### Linear — Grow traffic every N minutes until 100%

| Strategy | Description |
|----------|-------------|
| `Linear10PercentEvery3Minutes` | +10% every 3 min |
| `Linear10PercentEvery10Minutes` | +10% every 10 min |

### Canary — Try X%, then jump to 100%

| Strategy | Description |
|----------|-------------|
| `Canary10Percent5Minutes` | 10% for 5 min, then 100% |
| `Canary10Percent30Minutes` | 10% for 30 min, then 100% |

### AllAtOnce — Immediate switch

| Strategy | Description |
|----------|-------------|
| `AllAtOnce` | 0% → 100% instantly (fastest, most risky) |

```
  Linear:    ░░▓▓▓▓▓▓████████████████████  (gradual)
  Canary:    ░░▓▓▓▓░░░░████████████████████  (test, then flip)
  AllAtOnce: ░░██████████████████████████████  (instant)
```

---

## Rollbacks

- Create **pre and post traffic hooks** to check Lambda health
- If hooks fail OR a **CloudWatch Alarm** triggers → CodeDeploy **rolls back** to V1
- Automatic safety net

---

## AppSpec.yml Parameters

```yaml
version: 0.0

Resources:
  - myLambdaFunction:
      Type: AWS::Lambda::Function
      Properties:
        Name: myLambdaFunction              # (required) function name
        Alias: myLambdaFunctionAlias        # (required) alias name
        CurrentVersion: 1                   # (required) version traffic currently points to
        TargetVersion: 2                    # (required) version traffic will shift to
```

CodeDeploy updates the alias from `CurrentVersion` → `TargetVersion` over time using the chosen strategy.

---

## Exam Tips

- CodeDeploy automates **alias traffic shifting** between versions
- Three strategies: **Linear** (gradual), **Canary** (test then flip), **AllAtOnce** (instant)
- Rollbacks via **pre/post traffic hooks** or **CloudWatch Alarms**
- AppSpec.yml needs: **Name, Alias, CurrentVersion, TargetVersion**
- Practiced with the **SAM framework** (not standalone)
- `Canary10Percent5Minutes` = 10% for 5 min, then 100% (popular exam option)
