# 21.32 - Lambda Layers - Hands On

> **Lecture 295** | Section 21: AWS Serverless: Lambda
> Adding an AWS-provided Pandas layer to a Lambda function

---

## What Was Demonstrated

1. Created function `Lambda-layer-demo` (Python 3.13)
2. Used code that imports **Pandas** library → fails with `Unable to find module pandas`
3. Added an **AWS Layer**: `AWSSDKPandas-Python313` → function now works
4. The layer packages Pandas properly for Lambda — no manual packaging needed

## Key Takeaway

- Without layer → `ModuleNotFoundError`
- Add layer → works instantly
- AWS provides ready-made layers (like Pandas) — you can also create custom ones
