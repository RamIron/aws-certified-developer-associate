# 21.36 - Lambda External Dependencies

> **Lecture 299** | Section 21: AWS Serverless: Lambda
> How to package external libraries with your Lambda function code

---

## Packaging Dependencies

When your Lambda function needs external libraries (X-Ray SDK, DB clients, etc.), you must **package them together with your code** in a zip:

```
  your-function/
  ├── lambda_function.py       ← your code
  ├── node_modules/            ← JS dependencies (npm)
  ├── requirements/            ← Python deps (pip --target)
  └── lib/*.jar                ← Java dependencies
```

### Upload Rules

| Zip size | Upload method |
|----------|---------------|
| **< 50 MB** | Upload zip **directly** to Lambda |
| **≥ 50 MB** | Upload to **S3** first, then reference from Lambda |

---

## Key Points

- **Each language** has its own packaging approach (npm, pip --target, .jar files)
- **Native libraries** must be compiled on **Amazon Linux** to work on Lambda
- **AWS SDK is included by default** — no need to package it unless you need a specific version

---

## Exam Tips

- Dependencies must be **zipped with your code**
- Over 50 MB → upload to **S3 first**
- AWS SDK = **already included** in Lambda runtime
- Native libraries = compile on **Amazon Linux**
