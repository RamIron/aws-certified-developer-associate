# 21.12 - Lambda & CloudWatch Events / EventBridge Hands On

> Udemy Lecture #275 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### Setup Steps
1. **Create Lambda function** → `lambda-demo-eventbridge`, Python
2. **EventBridge console** → Rules → Create Rule
3. Name: `InvokeLambdaEveryMinute`, Default event bus
4. Rule type: **Schedule** (not event pattern)
5. Schedule: **rate(1 minute)**
6. Target: **Lambda function** → `lambda-demo-eventbridge`

### Two Rule Types

```
┌─────────────────────────────────┐
│ Event Pattern                   │
│ React to AWS events             │
│ (CodeCommit push, EC2 terminate)│
├─────────────────────────────────┤
│ Schedule                        │
│ Run on a cron or fixed rate     │
│ (every 1 minute, daily at 9am) │
└─────────────────────────────────┘
```

### Resource-Based Policy (auto-created)

When EventBridge rule targets a Lambda function, AWS automatically adds a **resource-based policy**:

```json
{
  "Effect": "Allow",
  "Principal": { "Service": "events.amazonaws.com" },
  "Action": "lambda:InvokeFunction",
  "Resource": "arn:aws:lambda:...:lambda-demo-eventbridge",
  "Condition": {
    "ArnLike": {
      "AWS:SourceArn": "arn:aws:events:...:rule/InvokeLambdaEveryMinute"
    }
  }
}
```

Only that specific EventBridge rule can invoke the function.

### Event Payload from EventBridge

```json
{
  "version": "0",
  "id": "...",
  "detail-type": "Scheduled Event",
  "source": "aws.events",
  "account": "123456789012",
  "time": "2026-03-25T...",
  "region": "eu-west-1",
  "resources": ["arn:aws:events:...:rule/InvokeLambdaEveryMinute"],
  "detail": {}
}
```

- `detail-type`: "Scheduled Event"
- `detail`: empty (no custom JSON provided)
- `source`: "aws.events"

### Clean Up
- **Disable the rule** when done (otherwise it keeps invoking every minute)

---

## Exam Tips

- EventBridge → Lambda = **resource-based policy** (auto-created, just like ALB → Lambda)
- Schedule events have `detail-type: "Scheduled Event"` and empty `detail`
- EventBridge Scheduler is a newer alternative with same capability, but classic EventBridge Rules still work
- Pattern: ALB, EventBridge → both auto-create resource-based policies on Lambda
