# 21.6 - Lambda Synchronous Invocations Hands On

> Udemy Lecture #269 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### Synchronous via Console
- Click **Test** in Lambda console → wait for result → get response
- If it takes 2 minutes, you wait 2 minutes — that's synchronous

### Synchronous via CLI

**List functions:**
```bash
aws lambda list-functions --region eu-west-1
```

**Invoke function synchronously:**
```bash
aws lambda invoke \
  --function-name demo-lambda \
  --payload '{"key1":"value1","key2":"value2"}' \
  response.json
```
- Returns status code `200` on success
- Response body written to `response.json`
- Uses CLI v2 (v1 has slightly different syntax)

### Key Observations
- Both console Test and CLI `invoke` are **synchronous** — caller waits for result
- CloudShell already has AWS CLI v2 installed + region auto-configured
- When using CLI from your terminal, add `--region` flag

---

## Exam Tips

- `aws lambda invoke` = synchronous invocation by default
- Console Test button = synchronous invocation
- Caller waits → gets response → handles errors client-side
