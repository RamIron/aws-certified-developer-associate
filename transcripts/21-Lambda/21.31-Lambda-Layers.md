# 21.31 - Lambda Layers

> **Lecture 294** | Section 21: AWS Serverless: Lambda
> Externalizing dependencies into reusable layers shared across Lambda functions

---

## What Are Lambda Layers?

Lambda Layers let you **package dependencies separately** from your function code. Two main use cases:

1. **Custom Runtimes** — run languages not natively supported (e.g., C++, Rust)
2. **Externalize Dependencies** — package heavy libraries once, reuse across functions

---

## Why Use Layers?

### Without Layers (Bad)
Every function bundles its own dependencies → large zip, slow deploys, repeated uploads.

```
  ┌─────────────────────────────┐
  │  Function A (30 MB zip)     │
  │  ┌────────────────────────┐ │
  │  │ Your code (20 KB)      │ │
  │  │ Heavy library (10 MB)  │ │
  │  │ Another lib (20 MB)    │ │
  │  └────────────────────────┘ │
  └─────────────────────────────┘

  Every deploy → re-upload 30 MB
  Another function with same libs? → duplicate everything
```

### With Layers (Good)
Separate code from dependencies. Code deploys are tiny, layers are reused.

```
  ┌──────────────────┐     ┌──────────────────┐
  │ Function A       │     │ Function B       │
  │ (20 KB)          │     │ (60 KB)          │
  └───────┬──────────┘     └───────┬──────────┘
          │                        │
          │    ┌───────────────┐   │
          ├───►│ Layer 1       │◄──┤
          │    │ (10 MB)       │   │
          │    └───────────────┘   │
          │    ┌───────────────┐   │
          └───►│ Layer 2       │◄──┘
               │ (30 MB)       │
               └───────────────┘

  Deploy Function A → upload 20 KB only!
  Deploy Function B → upload 60 KB only!
  Both share the same layers (no duplication)
```

---

## Key Benefits

- **Faster deployments** — only upload your code, not the dependencies
- **Reuse across functions** — multiple functions can reference the same layers
- **Independent updates** — update code without re-uploading unchanged dependencies

---

## Exam Tips

- Lambda Layers = **externalize dependencies** for reuse across functions
- Layers also enable **custom runtimes** (C++, Rust)
- Layers reduce **deployment package size** → faster deploys
- Multiple functions can **share the same layers**
