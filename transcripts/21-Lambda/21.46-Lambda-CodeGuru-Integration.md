# 21.46 - Lambda - CodeGuru Integration

> **Lecture 309** | Section 21: AWS Serverless: Lambda
> Profiling Lambda function runtime performance with CodeGuru

---

## CodeGuru Profiler + Lambda

- **CodeGuru Profiler** provides runtime performance insights for Lambda functions
- Supported for **Java and Python** runtimes only
- Activate from the **Lambda console** (simple toggle)

### What Happens When You Activate It

1. A **CodeGuru Profiler Lambda Layer** is added to your function
2. CodeGuru-related **environment variables** are added
3. **AmazonCodeGuruProfilerAgentAccess** policy is added to the function's IAM role

---

## Exam Tips

- CodeGuru Profiler on Lambda = **Java and Python** only
- Activation adds: **Lambda Layer** + **env vars** + **IAM policy** (AmazonCodeGuruProfilerAgentAccess)
- Provides runtime performance insights (not the same as X-Ray tracing)
