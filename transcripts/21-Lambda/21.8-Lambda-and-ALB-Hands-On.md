# 21.8 - Lambda & Application Load Balancer Hands On

> Udemy Lecture #271 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### Setup Steps
1. **Create Lambda function** → `lambda-alb`, Python, default role
2. **Create ALB** → `demo-lambda-alb`, internet-facing, 3 AZs
3. **Security Group** → allow HTTP (port 80) from anywhere
4. **Target Group** → type **Lambda function**, select `lambda-alb`
5. **ALB Listener** → port 80 → forward to Lambda target group

### Lambda Response Format

Initial code returned plain text → browser **downloaded** the file instead of displaying it.

Fix: return a proper HTTP response document:
```python
def lambda_handler(event, context):
    print(event)  # log the ALB event
    return {
        "statusCode": 200,
        "headers": {
            "Content-Type": "text/html"
        },
        "body": "<h1>Hello from Lambda</h1>"
    }
```

Key: `Content-Type: text/html` in headers → browser renders instead of downloading.

### What the ALB Event Looks Like

Visible in CloudWatch Logs (via `print(event)`):
```json
{
  "requestContext": { "elb": { "targetGroupArn": "..." } },
  "httpMethod": "GET",
  "path": "/",
  "queryStringParameters": {},
  "headers": {
    "host": "...",
    "user-agent": "...",
    "accept": "..."
  },
  "body": null,
  "isBase64Encoded": false
}
```

### Multi-Value Headers
- Found in **Target Group → Attributes**
- Toggle to enable/disable
- When enabled: headers and query params with same key → sent as arrays
- Lambda response code must also adapt to use `multiValueHeaders`

### Resource-Based Policy
- When you register Lambda in an ALB target group, AWS **automatically** creates a resource-based policy
- This policy allows the ALB to **invoke** the Lambda function
- Visible in Lambda → Configuration → Permissions → Resource-based policy

```
┌──────────────────────────────────────────┐
│  Resource-Based Policy (auto-created)    │
│                                          │
│  Effect: Allow                           │
│  Principal: elasticloadbalancing         │
│  Action: lambda:InvokeFunction           │
│  Resource: arn:aws:lambda:...:lambda-alb │
└──────────────────────────────────────────┘
```

---

## Exam Tips

- Lambda response must include `statusCode`, `headers`, `body`, `isBase64Encoded` for ALB
- `Content-Type: text/html` → browser renders; without it → downloads the file
- ALB → Lambda requires a **resource-based policy** (auto-created when you register)
- Multi-value headers is a **target group attribute** setting
- Clean up: delete the ALB when done (costs money while running)
