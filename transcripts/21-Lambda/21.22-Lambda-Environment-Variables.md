# 21.22 - Lambda Environment Variables

> Udemy Lecture #285 · Section 21: AWS Serverless: Lambda

## Key Concepts

### 1. What Are Environment Variables?

- **Key-value pairs** (string form) available to your Lambda function code
- **Max size: 4 KB** for all environment variables combined
- Adjust function behavior **without changing code** (e.g., DB connection string, API URL, feature flags)
- Lambda also adds its own **system environment variables** automatically

### 2. Encryption with KMS

Environment variables can be encrypted for storing secrets:

```
┌──────────────────────────────────────────────┐
│  Encryption Options                          │
│                                              │
│  1. Lambda service key (default, free)       │
│     → AWS manages the key                    │
│                                              │
│  2. Customer Master Key (CMK)                │
│     → You manage the key in KMS              │
│     → More control, can audit usage          │
└──────────────────────────────────────────────┘
```

---

## Exam Tips

- Environment variables = key-value pairs, always **strings**
- Change behavior without redeploying code
- Encrypt secrets with **KMS** (Lambda service key or your own CMK)
- Common use: DB URLs, API keys, feature toggles, stage name (dev/prod)
