# 21.25 - Lambda Monitoring & X-Ray Tracing - Hands On

> Udemy Lecture #288 · Section 21: AWS Serverless: Lambda

## Hands-On Summary

### CloudWatch Metrics in Lambda Console

Lambda → Monitor tab → Metrics shows:

| Metric | What Was Shown |
|--------|---------------|
| **Invocations** | How many times function was called |
| **Duration** | How long each invocation lasted |
| **Error Count / Success Rate** | Green = success, Red = error (visible timeline) |
| **Throttles** | If hitting Lambda concurrency limits |
| **Async Delivery Failures** | Events that couldn't be processed |
| **Iterator Age** | Lag when reading from Kinesis/DDB streams |
| **Concurrent Executions** | How many instances running at same time |

### CloudWatch Logs

Each invocation creates log entries with:
- **Request ID** at start and end
- **Report line**: duration, billed duration, memory size, max memory used, init duration (cold start)

### Enabling X-Ray Active Tracing

1. Lambda → Configuration → **Monitoring and operation tools** → Edit
2. Enable **AWS X-Ray** → Active tracing ON
3. **Permission error** → console auto-fixes by adding `AWSXRayDaemonWriteAccess` to execution role
4. Save

### Verifying X-Ray Permissions

Lambda execution role now has:
- **CloudWatch Logs** → CreateLogGroup, CreateLogStream, PutLogEvents
- **SQS** → for destinations (SendMessage)
- **X-Ray** → `PutTraceSegments`, `PutTelemetryRecords`

### X-Ray Service Map

After uploading files to S3 → Lambda processes them → traces appear in X-Ray console (~5 min delay):
- Client → Lambda function → shows green (success) and orange (errors)
- Visual service map of the invocation chain

---

## Exam Tips

- Enable X-Ray on Lambda: **Configuration → Monitoring → Active tracing ON**
- Console auto-adds `AWSXRayDaemonWriteAccess` to execution role
- X-Ray permissions needed: `PutTraceSegments` + `PutTelemetryRecords`
- Lambda log **report line** shows: duration, billed duration, memory size, **max memory used**, init duration
- **Max memory used** is useful to see if you need to increase/decrease RAM allocation
- X-Ray traces may take **~5 minutes** to appear in console
