# 21.30 - Lambda Function Performance - Hands On

> **Lecture 293** | Section 21: AWS Serverless: Lambda
> Demonstrating memory, timeout, and execution context behavior in the console

---

## What Was Demonstrated

### 1. Memory Configuration
- General Configuration → Edit Basic Settings
- Memory range: **128 MB to 10,240 MB (10 GB)**
- CPU is **proportionally allocated** to memory — no independent CPU setting
- Monitor memory usage to avoid over-billing

### 2. Timeout Demo
- Default: **3 seconds**
- Used `time.sleep(2)` → function succeeds (2s < 3s timeout) ✅
- Changed to `time.sleep(5)` → function **fails** with timeout error (5s > 3s timeout) ❌
- Increased timeout to 6 seconds → function succeeds again ✅

> **Why not set timeout to max (15 min)?** If your function gets stuck, you want it to fail fast so you can detect and fix the issue. Set timeout to a reasonable value based on expected execution time.

### 3. Execution Context Demo (Init Inside vs Outside Handler)

**Inside handler (bad):**
```python
def handler(event, context):
    connect_to_db()          # 3 seconds every invocation
    return response
```
- Every test: **~3 seconds** (connects to DB every time)

**Outside handler (good):**
```python
def connect_to_db():
    time.sleep(3)            # simulates DB connection

connect_to_db()              # runs ONCE during INIT

def handler(event, context):
    return response
```
- First test: **3 seconds** (INIT duration = 3000 ms, function duration = 1 ms)
- Subsequent tests: **< 1 ms** (INIT already done, reused!)

### Key Observation: INIT Duration
- In CloudWatch logs, the first invocation shows **Init Duration: ~3000 ms**
- This is the cold start — running code outside the handler
- Subsequent invocations skip INIT → much faster

---

## Exam Relevance

- Need faster CPU? → **Increase memory** (no independent CPU setting)
- Set timeout **appropriately** — not too high, not too low
- Code outside handler = runs once = **INIT duration** (cold start)
- Code inside handler = runs every time = slow repeated invocations
