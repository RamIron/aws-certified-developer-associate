03 — Security Groups03 — Grupos de seguridad
Only ALLOW rules — you cannot write explicit deny rules in a security groupSolo reglas de PERMITIR — no puedes escribir reglas de denegación explícitas en un grupo de seguridad
Live OUTSIDE the EC2 instance — EC2 never sees blocked traffic; it is dropped at the SG levelViven FUERA de la instancia EC2 — EC2 nunca ve tráfico bloqueado; se descarta a nivel del SG
Default behavior: all inbound traffic BLOCKED, all outbound traffic ALLOWEDComportamiento predeterminado: todo el tráfico entrante BLOQUEADO, todo el tráfico saliente PERMITIDO
Can reference other Security Groups as a source/destination — not just IP ranges or CIDR blocksPuede hacer referencia a otros grupos de seguridad como origen/destino — no solo rangos de IP o bloques CIDR
Stateful: return traffic is automatically allowed. If inbound is allowed, the response is allowed outboundCon estado: el tráfico de retorno se permite automáticamente. Si se permite la entrada, la respuesta se permite hacia afuera
