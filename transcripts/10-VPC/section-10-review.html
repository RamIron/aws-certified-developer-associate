1 — VPC & Subnets Overview1 — Descripción general de VPC y subredes
What Is a VPC?¿Qué es una VPC?

A VPC (Virtual Private Cloud) is your private network inside AWS. You define the IP range, create subnets, and control routing and access.Una VPC (Nube Privada Virtual) es su red privada dentro de AWS. Define el rango de IP, crea subredes y controla el enrutamiento y el acceso.

VPC — Regional ResourceVPC — Recurso Regional
  • Spans ALL Availability Zones in a regionAbarca TODAS las zonas de disponibilidad de una región
  • You define a CIDR block (e.g.,Defines un bloque CIDR (por ejemplo, 10.0.0.0/16)
  • Max 5 VPCs per region (soft limit)Máx. 5 VPC por región (límite flexible)
  • Each AWS account gets a default VPCCada cuenta de AWS obtiene una VPC predeterminada
Subnet — AZ-LevelNivel ResourceSubred — Recurso a nivel de AZ
  • Lives inside one specific AZVive dentro de una AZ específica
  • Sub-range of the VPC CIDR (e.g.,Subrango del CIDR de VPC (por ejemplo, 10.0.1.0/24)
  • AWS reserves 5 IPs per subnet (first 4 + last 1)AWS reserva 5 IP por subred (primeras 4 + última 1)
  • Public or Private depending on route tablePúblico o privado según la tabla de rutas
Public SubnetSubred Pública
Has a route to an Internet Gateway in its route table. Resources can be accessed from the internet (if allowed by SG). Use for: ELB, Bastion hosts, NAT Gateway.Tiene una ruta a una Puerta de enlace a Internet en su tabla de rutas. Se puede acceder a los recursos desde Internet (si lo permite el SG). Use para: ELB, hosts bastión, NAT Gateway.
Private SubnetSubred Privada
No route to an Internet Gateway. Isolated from the public internet. Use for: application servers, databases, caches. Can reach internet outbound only via NAT.Sin ruta a una Puerta de enlace a Internet. Aislado de Internet público. Use para: servidores de aplicaciones, bases de datos, cachés. Puede alcanzar Internet solo saliente vía NAT.
Default VPC:VPC Predeterminada: Every AWS account has one. All subnets are public (one per AZ). CIDR block is 172.31.0.0/16. Instances launched here get both a public and private IP by default. Safe to use for learning — do NOT delete it.Cada cuenta de AWS tiene una. Todas las subredes son públicas (una por AZ). El bloque CIDR es 172.31.0.0/16. Las instancias lanzadas aquí obtienen tanto IP pública como privada de forma predeterminada. Es seguro usar para aprender — NO la elimine.

They are the primary tool for diagnosing connectivity issues.Los registros de flujo de VPC capturan metadatos sobre todo el tráfico IP que va hacia y desde interfaces de red. Son la herramienta principal para diagnosticar problemas de conectividad.

VPC

Exam trap:Trampa del examen: Flow Logs do NOT capture traffic to/from the AWS DNS server (169.254.169.253), the link-local address (169.254.169.254 for metadata), or DHCP traffic. Use Flow Logs to diagnose NACL vs Security GroupGrupo de seguridad issues — look for ACCEPT vs REJECT in the logs.Los registros de flujo NO capturan tráfico hacia/desde el servidor DNS de AWS (169.254.169.253), la dirección de enlace local (169.254.169.254 para metadatos), o tráfico DHCP. Use registros de flujo para diagnosticar problemas de ACL de red vs grupo de seguridad — busque ACEPTAR vs RECHAZAR en los registros.
5 — VPC Peering5 — Emparejamiento de VPC
Connecting VPCs Privately via the AWS NetworkConectar VPC de forma privada a través de la red de AWS

VPC Peering lets two VPCs communicate as if they were on the same private network — no internet involved. It works within the same account, across accounts, and across regions.El emparejamiento de VPC permite que dos VPC se comuniquen como si estuvieran en la misma red privada — sin Internet involucrado. Funciona dentro de la misma cuenta, entre cuentas y entre regiones.

Requirements & ConstraintsRequisitos y restricciones
  • IP CIDR ranges must NOT overlapLos rangos CIDR de IP NO deben superponerse
  • NOT transitive — each pair needs its own peering connectionNO transitivo — cada par necesita su propia conexión de emparejamiento
  • Both VPCs need updated route tables after peeringAmbas VPC necesitan tablas de rutas actualizadas después del emparejamiento
  • Works across different AWS accountsFunciona entre diferentes cuentas de AWS
  • Works across different regionsFunciona entre diferentes regiones
Non-Transitivity ExplainedTransitividad No explicada

If A–B peered and B–C peered, A cannot reach C automatically. You must create A–C peering separately.Si A–B están emparejadas y B–C están emparejadas, A no puede alcanzar C automáticamente. Debes crear el emparejamiento A–C por separado.

VPC-A →← VPC-B PeeredEmparejado
VPC-A →← VPC-C PeeredEmparejado
VPC-B ✕ VPC-C No path!¡Sin camino!
Key exam point:Punto clave del examen: VPC Peering is NOT transitive. If you need any-to-any connectivity between many VPCs, consider AWS Transit Gateway instead (hub-and-spoke model, supports transitive routing).
6 — VPC Endpoints6 — Puntos de enlace de VPC
Private Access to AWS Services — No Internet RequiredAcceso privado a servicios de AWS — No se requiere Internet

VPC Endpoints let resources in your private subnets reach AWS services without traffic ever leaving the AWS network.Los puntos de enlace de VPC permiten que los recursos en sus subredes privadas accedan a los servicios de AWS sin que el tráfico salga de la red de AWS.

Gateway EndpointPunto de enlace de puerta de enlace
  • Supports S3 and DynamoDB ONLY
  • Implemented as a route in the VPC route tableImplementado como una ruta en la tabla de rutas de VPC
  • No ENI — no per-hour cost (completely FREE)Sin ENI — sin costo por hora (completamente GRATIS)
  • Associated with specific route tables in specific subnetsAsociado con tablas de rutas específicas en subredes específicas
  • Does not require a private DNS nameNo requiere un nombre DNS privado
Interface Endpoint (PrivateLink)Punto de enlace de interfaz (PrivateLink)
  • Supports all other AWS services (SQS, SNS, KMS, etc.)
  • Creates an ENI in your subnet — uses private IPCrea una ENI en su subred — usa IP privada
  • Billed per hour + per GB of data processedSe factura por hora + por GB de datos procesados
  • Provides private DNS name for the serviceProporciona nombre DNS privado para el servicio
  • Can be used from Direct Connect / Site-to-Site VPNSe puede usar desde Direct Connect / VPN de sitio a sitio
Free tip for the exam:Consejo gratis para el examen: Gateway EndpointPunto de enlace de puerta de enlace for S3 is free AND the recommended approach for EC2/Lambda in private subnets needing S3 access. Interface Endpoints cost money but support every service.El punto de enlace de puerta de enlace para S3 es gratuito Y el enfoque recomendado para EC2/Lambda en subredes privadas que necesitan acceso a S3. Los puntos de enlace de interfaz cuestan dinero pero admiten todos los servicios.
