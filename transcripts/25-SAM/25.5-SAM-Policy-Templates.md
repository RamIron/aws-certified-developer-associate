# 25.5 - AWS SAM - SAM Policy Templates

**Status:** ✅ Completed

## Key Concepts

### 1. What are SAM Policy Templates?
- A list of pre-built IAM permission templates you can attach to Lambda functions
- Replace the need to write raw IAM roles/policies in CloudFormation
- The SAM framework transforms them into proper IAM policies at deploy time
- Full list available in AWS docs — many options, but 3 are exam-relevant

### 2. Three Key Examples
| Policy Template | What it grants |
|---|---|
| `S3ReadPolicy` | Read-only access to objects in an S3 bucket |
| `SQSPollerPolicy` | Permission to poll an SQS queue |
| `DynamoDBCrudPolicy` | Create, Read, Update, Delete on a DynamoDB table |

### 3. Usage in Template
```yaml
MyFunction:
  Type: AWS::Serverless::Function
  Properties:
    Runtime: python3.12
    Policies:
      - SQSPollerPolicy:
          QueueName: !GetAtt MyQueue.QueueName
```
SAM transforms this one-liner into a full IAM policy automatically.

## Exam Tips
- The name of the policy template is self-explanatory — if you see the name, you know what it does
- Key point: SAM policy templates **replace raw IAM role definitions** — simpler and less error-prone
- Know the 3 examples: S3ReadPolicy, SQSPollerPolicy, DynamoDBCrudPolicy
