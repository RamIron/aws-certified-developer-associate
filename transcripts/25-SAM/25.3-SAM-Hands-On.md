# 25.3 - AWS SAM - Hands On

**Status:** ⏭️ Skipped (hands-on)

## What was covered

- `sam init` — initialize a project from a Quick Start template (Hello World, data processing, DynamoDB, etc.)
- Project structure:
  - `hello_world/app.py` — Lambda handler code (Python)
  - `requirements.txt` — Python package dependencies
  - `samconfig.toml` — SAM config (stack name, region, build params, etc.)
  - `template.yaml` — SAM template with `Transform` header and `AWS::Serverless::Function` resource
- `sam build` — compiles code + installs dependencies → produces `.aws-sam/` directory with build artifacts
- `sam deploy --guided` — interactive deploy: prompts for stack name, region, IAM permissions, etc. Saves answers to `samconfig.toml` for subsequent deploys
- Result: CloudFormation creates Lambda + API Gateway → API returns `{"message": "Hello world"}`

## Notes
- CloudShell has SAM CLI pre-installed
- `sam deploy --guided` only needed once; subsequent deploys just use `sam deploy`
- SAM creates a managed S3 bucket and IAM role automatically on first deploy
