Common Exam ScenarioEscenario común del examen

Source images in /images/ prefix → Glacier after 60 days. Thumbnails in /thumbs/ prefix → One-Zone-IA → expire after 60 days. Use separate prefix-based rules for each.Imágenes de origen en el prefijo /images/ → Glacier después de 60 días. Miniaturas en el prefijo /thumbs/ → One-Zone-IA → expiran después de 60 días. Use reglas separadas basadas en prefijo para cada una.

Versioning + Lifecycle: Enable versioning to protect against accidental deletes. Then create lifecycle rules for non-current versions: Standard-IA after 30 days → Glacier Deep Archive after 90 days. This enables cost-effective recovery without keeping live copies in Standard storage.Control de versiones + Ciclo de vida: Habilite el control de versiones para proteger contra eliminaciones accidentales. Luego cree reglas de ciclo de vida para versiones no actuales: Standard-IA después de 30 días → Glacier Deep Archive después de 90 días. Esto permite recuperación rentable sin mantener copias en vivo en almacenamiento estándar.

Download Optimization — Byte-Range FetchesOptimización de descarga — Recuperación por rango de bytes
Parallel DownloadsDescargas paralelas

Request specific byte ranges of an object simultaneously from multiple threads. Significantly improves download throughput for large files. If a range request fails, retry only that range — not the entire file.Solicite rangos de bytes específicos de un objeto simultáneamente desde múltiples hilos. Mejora significativamente la velocidad de transferencia de descarga para archivos grandes. Si una solicitud de rango falla, reintente solo ese rango, no el archivo completo.

Partial File ReadsLecturas parciales de archivos

Retrieve only the header of a file (first N bytes) without downloading the entire object. Useful for reading file metadata, magic bytes, or CSV headers stored in S3 at minimal cost.Recupere solo el encabezado de un archivo (primeros N bytes) sin descargar el objeto completo. Útil para leer metadatos de archivo, bytes mágicos o encabezados CSV almacenados en S3 con costo mínimo.

Critical Exam Point — Neither metadata nor tags are searchable in S3.
You cannot query S3 like a database. To find objects by metadata or tag values, you must build an external index in DynamoDB, query DynamoDB first to get the S3 key, then fetch the object from S3.Punto crítico del examen — Ni los metadatos ni las etiquetas se pueden buscar en S3.
No puede consultar S3 como una base de datos. Para encontrar objetos por valores de metadatos o etiquetas, debe crear un índice externo en DynamoDB, consultar DynamoDB primero para obtener la clave S3 y luego recuperar el objeto de S3.
