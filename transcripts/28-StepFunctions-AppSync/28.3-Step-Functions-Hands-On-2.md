# 28.3 — Step Functions — Hands On (Lambda integration)

## Summary
Console walkthrough building a state machine that invokes a Lambda function and uses a Choice state to branch based on the output.

## Key Note
- When a state machine needs to access other AWS services (Lambda, X-Ray, etc.), an **IAM execution role is automatically created** with the required permissions — no manual role setup needed.
- Choice state evaluates the **output** of a previous task state to decide the next branch.
