# 28.2 — Step Functions — Hands On

## Summary
Console walkthrough of the Hello World example. Key takeaways are the ASL format name, the two workflow types, and the Workflow Studio interface.

---

## Key Notes

### Amazon States Language (ASL)
- The JSON format used to define Step Functions workflows is officially called **Amazon States Language (ASL)**
- The Workflow Studio generates ASL automatically from the drag-and-drop canvas

### Workflow Studio
- Drag-and-drop console builder — services on left, canvas in center, ASL on right
- Supports Lambda, all major AWS services, Flow states (Choice, Parallel, Map), and patterns

### Standard vs Express Workflows
- Configured at creation time
- Difference is about **duration and cost** (covered in more detail in further lessons)

### Visual Execution Features
- Per-state: input, output, variables at each step
- Event History tab: full chronological log of all state transitions
- Variables can be tracked across states (e.g. CheckpointCount incrementing)
