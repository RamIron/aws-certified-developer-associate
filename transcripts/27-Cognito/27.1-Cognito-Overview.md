# 27.1 - Cognito Overview

## Key Concepts

### What is Amazon Cognito?
- Gives **identity** to users of web and mobile applications
- Users typically sit **outside of AWS** (not IAM users)
- Name hint: "Cognito" → identity for users we don't know yet

### Two Sub-Services

| Service | Purpose | Integration |
|---|---|---|
| **Cognito User Pool (CUP)** | Sign-in functionality for app users | API Gateway, ALB |
| **Cognito Identity Pool** (Federated Identity) | Temporary AWS credentials for app users | Works with Cognito User Pool |

### Cognito vs IAM
- IAM = users **inside** AWS
- Cognito = users **outside** AWS (web/mobile app users)

### Exam Keywords
- Hundreds/millions of users
- Mobile users
- Authentication with external mechanisms (SAML, social login)
- Web/mobile application users needing AWS access

## Summary
Cognito solves the problem of managing identity for external users (not AWS staff/admins). Use CUP for authentication (sign-in), use Identity Pool to grant temporary AWS credentials.
