# 27.4 - Cognito User Pools - Others

## Lambda Triggers (deep dive)

CUP invokes Lambda **synchronously** at specific lifecycle events:

### Authentication Events
| Trigger | Use case |
|---|---|
| Pre-authentication | Accept or deny sign-in request |
| Post-authentication | Log events / custom analytics after login |
| Pre-token generation | Augment or suppress token claims |

### Sign-up Events
| Trigger | Use case |
|---|---|
| Pre sign-up | Custom validation before user is created |
| Post confirmation | Welcome message / event logging after user confirms |
| Migrate user | Migrate users from legacy user pool |

### Message Customization
- Lambda can customize verification emails/SMS sent to users

## Hosted UI / Managed Login
- AWS-provided login page (sign-up, sign-in, forgot password)
- Supports social login, OIDC, SAML out of the box
- Customizable: logo + CSS (no need to build your own auth UI)

### Custom Domain + HTTPS (⚠️ Exam trap)
- To use a custom domain with Hosted UI, you MUST:
  1. Create an SSL certificate in **ACM**
  2. The ACM certificate **MUST be in us-east-1** — regardless of where your User Pool is
  3. Define the custom domain in the **App Integration** section of CUP

## Adaptive Authentication
- Cognito assigns a **risk score** (low / medium / high) to each sign-in attempt
- Based on: device, location, IP address
- If risky → user may be prompted for MFA only when risk is detected
- Also handles: compromised credentials, account takeover protection
- All activity logged in **CloudWatch Logs**

## JWT Token Structure
A Cognito JWT has 3 parts (Base64 encoded):
```
header.payload.signature
```

### Payload (key fields)
| Field | Meaning |
|---|---|
| `sub` | UUID — user's unique ID in the Cognito User Pool |
| `username` | Cognito username |
| `cognito:groups` | Groups the user belongs to |
| `exp` | Token expiry |

### Verifying a JWT
- **Always verify the signature** before trusting payload claims
- Libraries available for all languages
- Once verified → use `sub` UUID to look up user attributes from Cognito DB

## Exam Tips
- Custom domain for Hosted UI → ACM cert **must be in us-east-1**
- JWT `sub` field = user ID in CUP
- Adaptive authentication → risk score → automatic MFA challenge
- Lambda triggers are invoked **synchronously**
- Pre-token generation trigger → modify token claims (add/remove attributes)
