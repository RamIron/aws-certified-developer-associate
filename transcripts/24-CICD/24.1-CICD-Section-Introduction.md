# 24.1 - AWS CICD - Section Introduction

**Section:** 24 — AWS CICD: CodeCommit, CodePipeline, CodeBuild, CodeDeploy
**Type:** Introduction (no quiz)

## Summary

Brief intro lesson. Key points:

- Goal: push code → automatically deploy to production
- This is called **CI/CD**
- AWS has native services for the full CI/CD pipeline
- Exam will have many questions on this topic

## Services covered in this section

| Service | Role |
|---|---|
| CodeCommit | Source control (Git repos) |
| CodePipeline | Orchestrates the pipeline |
| CodeBuild | Build & test |
| CodeDeploy | Deploy to EC2, Lambda, ECS |

Intro only — no technical content. Next lesson (24.2) covers the concepts in depth.
