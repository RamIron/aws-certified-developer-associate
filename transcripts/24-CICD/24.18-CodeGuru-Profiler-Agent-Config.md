# 24.18 - Amazon CodeGuru Profiler — Agent Configuration

> Short lesson covering the Profiler agent settings. No need to memorize all — understand what each does so you can reason through exam questions.

## Agent Parameters

| Parameter | What it controls |
|-----------|-----------------|
| **MaxStackDepth** | How deep the call stack is profiled. Depth = number of nested method calls tracked. e.g. A→B→C→D = depth 4. If set to 2, only A and B are profiled. |
| **MemoryUsageLimitPercent** | Max % of memory the profiler agent is allowed to use. |
| **MinimumTimeForReportingInMilliseconds** | Minimum interval between sending reports to CodeGuru. |
| **ReportingIntervalInMilliseconds** | How often the agent sends profiling data (bounded by the minimum above). |
| **SamplingIntervalInMilliseconds** | How often the agent samples the app. Lower value = higher sampling rate = more methods captured = more detail (but more overhead). |

## Key Rule for the Exam

Don't memorize values — understand the **direction of effect**:
- Lower `SamplingIntervalInMilliseconds` → more frequent samples → more detail
- Higher `MaxStackDepth` → deeper call stack profiled
- These names are self-descriptive: reason from the name if it shows up on the exam.
