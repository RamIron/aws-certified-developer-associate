## Summary

Hands-on walkthrough of creating a CodeBuild project in the AWS console:

- Source connected to **GitHub** via OAuth
- Managed image: **Ubuntu**, Standard runtime, latest image
- New IAM service role created: `CodeBuildDemoServiceRole`
- Buildspec: uses `buildspec.yml` from the source code root directory
- Build failed (expected) — `buildspec.yml` not yet added to the repo
- **VPC option** highlighted: CodeBuild containers run outside VPC by default; you can configure a specific VPC to give access to databases or other internal resources

## Exam Note

> Configuring CodeBuild to run **inside a VPC** allows it to access private resources (RDS, ElastiCache, internal services) that are not publicly reachable.
