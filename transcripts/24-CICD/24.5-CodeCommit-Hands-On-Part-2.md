## Where to Configure CodeCommit Credentials (IAM)

Both authentication methods are configured under:
**IAM → Users → [user] → Security Credentials → scroll down**

| Method | Where in IAM | How it works |
|---|---|---|
| SSH | "SSH keys for AWS CodeCommit" | Upload your public key → use SSH clone URL |
| HTTPS | "HTTPS Git credentials for AWS CodeCommit" | Generate username/password (up to 2 pairs) → use HTTPS clone URL |

- Root account → SSH option is NOT available (IAM user required)
- Up to **2** HTTPS credential pairs can be active per IAM user

## Typical Git Workflow with CodeCommit

```bash
git clone <HTTPS or SSH CodeCommit URL>   # clone repo locally
# ... add/edit files ...
git status                                 # see untracked/modified files
git add .                                  # stage all changes
git commit -m "your message"              # commit locally
git push                                   # push to CodeCommit
```

No different from any other Git remote — only the URL and credentials differ.

## Exam Tips
- SSH keys and HTTPS credentials for CodeCommit are configured in **IAM user Security Credentials**
- SSH → upload public key; HTTPS → generate username/password
- Root account cannot use SSH with CodeCommit
