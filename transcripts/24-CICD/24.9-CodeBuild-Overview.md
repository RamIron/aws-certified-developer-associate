# 24.9 - CodeBuild Overview

## Key Concepts

### 1. What is CodeBuild?
- Fully managed build service — takes source code and runs build/test instructions
- Source can be: CodeCommit, S3, Bitbucket, GitHub
- Build instructions live in **`buildspec.yml`** at the **root** of the repo
- Alternatively, instructions can be entered manually in the console (but NOT best practice)

### 2. Supported Environments (pre-built Docker images)
Java, Ruby, Python, Go, Node.js, Android, .NET Core, PHP
- For anything else: extend a **Docker image** to support any environment

### 3. How CodeBuild Works
```
Source code (CodeCommit / GitHub / S3 / Bitbucket)
    └── includes buildspec.yml at root
          │
          ▼
CodeBuild pulls Docker image (AWS pre-built or custom)
          │
          ▼
Container loads source + buildspec.yml → runs all instructions
          │
          ├── Logs → CloudWatch Logs + S3 (if enabled)
          ├── Cache (optional) → S3 (reuse deps between builds)
          └── Artifacts (output) → S3 bucket
```

### 4. buildspec.yml Structure
Must be at the **root** of the code directory.

| Section | Purpose |
|---|---|
| `env` | Environment variables — plaintext, SSM Parameter Store, or Secrets Manager |
| `phases.install` | Install pre-required packages |
| `phases.pre_build` | Commands to run just before the build |
| `phases.build` | The actual build commands |
| `phases.post_build` | Finishing touches (e.g. create zip output) |
| `artifacts` | Which files to extract from the container → sent to S3 (encrypted) |
| `cache` | Files (usually dependencies) to cache in S3 for faster future builds |

### 5. Monitoring & Integration
| Tool | Use |
|---|---|
| CloudWatch Logs | Build logs |
| Amazon S3 | Logs + artifacts + cache |
| CloudWatch Metrics | Build statistics |
| EventBridge | Detect failed builds, trigger notifications |
| CloudWatch Alarms | Alert on too many failures |

### 6. CodeBuild in CodePipeline
- Build Projects can be defined inside CodeBuild **or** within CodePipeline
- CodePipeline can also invoke an **existing** CodeBuild Build Project

## Exam Tips
- Build instructions file = **`buildspec.yml`**, must be at the **root** of the repo
- Secrets/passwords in build → pull from **SSM Parameter Store** or **Secrets Manager** (never plaintext in buildspec.yml)
- Custom environment → extend a **Docker image**
- Artifacts output → **S3**
- Failed build notifications → **EventBridge**
- Cache between builds → **S3**
