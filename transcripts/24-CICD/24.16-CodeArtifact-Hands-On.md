# 24.16 - CodeArtifact - Hands On

**Status:** Skipped (hands-on)

## Key Steps Shown

1. Create a **domain** (`my-company`) — represents the company, requires a KMS key (AWS managed key is fine)
2. Create a **repository** (`demo-repository`) with upstream → `pypi-store` (which has an external connection to public PyPI)
3. Get an **authorization token** via CLI:
   ```bash
   export CODEARTIFACT_AUTH_TOKEN=$(aws codeartifact get-authorization-token \
     --domain my-company --domain-owner <account-id> --query authorizationToken --output text)
   ```
   Token is valid for **12 hours**.
4. Configure pip to point to CodeArtifact:
   ```bash
   pip3 config set global.index-url https://aws:$CODEARTIFACT_AUTH_TOKEN@my-company-<account>.d.codeartifact.<region>.amazonaws.com/pypi/demo-repository/simple/
   ```
5. Install a package → CodeArtifact caches it (and all its dependencies) in the repo
6. Packages appear in **both** the upstream repo (pypi-store) and demo-repository

## Notable Details

- CloudShell has `pip3`, not `pip` — adjust commands accordingly
- Multiple versions of the same package can be cached (e.g. 0.4.0 and 0.5.0 of `response`)
- Repository policies can be applied at **repo level** (read-only / read+publish / full access)
- Domain policies can be applied at **domain level** for cross-account/org access

## Cleanup

Delete repositories → delete domain.
