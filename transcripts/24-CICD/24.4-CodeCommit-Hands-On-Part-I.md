## Notable Details from the Walkthrough

### SSH availability
- SSH connection option is **only shown when connected as an IAM User**, NOT as root account
- If you don't see SSH in the connection steps → you're using root

### Notifications vs Triggers
| | Notifications | Triggers |
|---|---|---|
| Purpose | Inform humans/teams about repo events | Invoke a service when specific code events occur |
| Events covered | Comments, PRs, approvals, branches/tags | Push to branch, create/delete branch or tag |
| Targets | SNS topic, AWS Chatbot (Slack) | SNS topic, **Lambda function** |
| SNS naming | Must start with `codestar-notification` | Any SNS topic |

### Branches
- Default branch name is **main** (previously called `master` — updated by AWS)
- Additional branches (dev, test, etc.) can be created for developer collaboration
- Pull requests merge changes from other branches into master

## Exam Tips
- Cross-account: SSH only for IAM users, not root
- Triggers can invoke **Lambda** directly; Notifications cannot (they go to SNS/Chatbot)
- SNS topic for notifications must be prefixed: `codestar-notification-*`
