# 24.17 - Amazon CodeGuru

> ⚠️ **Note:** CodeGuru is being decommissioned. Still included in case it appears on the exam.

## Two Components

### CodeGuru Reviewer — Automated Code Reviews
- Static code analysis on commits (CodeCommit, GitHub, Bitbucket)
- Detects: critical issues, security vulnerabilities, resource leaks, hard-to-find bugs, input validation issues
- ML-trained on thousands of open source repos + Amazon's internal repos
- Supports: **Java and Python**
- Integrations: GitHub, Bitbucket, CodeCommit

### CodeGuru Profiler — Performance Recommendations
- Works in **pre-production** (build/test) and **production** (runtime)
- Detects expensive lines of code, CPU waste, memory issues
- Provides: heap summaries, anomaly detection, cost improvement recommendations
- Supports apps on **AWS Cloud or on-premises**
- Minimal overhead on monitored application

## Exam Tips
- Know the two components: **Reviewer** (code quality) and **Profiler** (performance)
- Reviewer = static analysis on push; Profiler = runtime analysis in prod/pre-prod
- ML-powered, trained on Amazon + open source repos
- Java and Python only (for Reviewer)
