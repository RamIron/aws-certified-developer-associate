# 24.12 - CodeDeploy Overview

## Key Concepts

### 1. What is CodeDeploy?
- Automates application deployment (v1 → v2)
- Targets: **EC2/on-premises**, **Lambda functions**, **ECS services**
- Supports **rollback** — automatic on failure or alarm trigger
- Deployment speed control: AllAtOnce, HalfAtATime, OneAtATime, Custom
- Deployment instructions defined in **`appspec.yml`**

### 2. EC2 / On-Premises Platform
- Two deployment types: **in-place** and **blue/green**
- Requires **CodeDeploy agent** installed on target instances
- Agent downloads the application revision from **S3** (EC2 needs IAM permissions for S3)
- Agent can be installed via Linux commands or automated via **Systems Manager**

#### Deployment Speeds
| Speed | Behavior | Downtime |
|---|---|---|
| `AllAtOnce` | Updates all instances simultaneously | Highest |
| `HalfAtATime` | Updates 50% at a time | Medium |
| `OneAtATime` | Updates one instance at a time | Lowest |
| Custom | Define your own % | Varies |

#### In-Place (HalfAtATime example)
1. Agent takes down 2 of 4 instances (stops app)
2. Deploys v2 on those 2 instances
3. Brings them back up
4. Repeats for the other 2

#### Blue/Green
- ALB points to v1 Auto Scaling group (blue)
- CodeDeploy creates a new ASG with v2 instances (green)
- ALB traffic shifted to green
- Blue ASG terminated

### 3. Lambda Platform
- Automates **traffic shifting** between Lambda aliases (v1 → v2 under PROD alias)
- Fully integrated with the **SAM framework**

#### Traffic Shift Strategies
| Strategy | Behavior |
|---|---|
| `LambdaLinear10PercentEvery3Minutes` | +10% every 3 min until 100% |
| `LambdaLinear10PercentEvery10Minutes` | +10% every 10 min until 100% |
| `LambdaCanary10Percent5Minutes` | 10% for 5 min → then 100% |
| `LambdaCanary10Percent30Minutes` | 10% for 30 min → then 100% |
| `LambdaAllAtOnce` | Immediate switch, no testing window |

### 4. ECS Platform
- Automates deployment of a new **ECS task definition**
- **Blue/green only** (no in-place for ECS)
- ALB shifts traffic from v1 target group (blue) → v2 target group (green)
- Same traffic shifting strategies as Lambda: Linear, Canary, AllAtOnce

## Exam Tips
- appspec.yml controls how CodeDeploy deploys
- EC2/on-premises → needs **CodeDeploy agent** on each instance
- Agent pulls revision from **S3** → EC2 needs IAM permissions for S3
- Lambda → **traffic shifting on alias** (Linear / Canary / AllAtOnce)
- ECS → **blue/green only**
- Rollback is automatic on failure or CloudWatch Alarm trigger
