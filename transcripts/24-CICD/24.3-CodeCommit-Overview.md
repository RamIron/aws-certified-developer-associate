# 24.3 - CodeCommit Overview

## Key Concepts

### 1. Version Control & Git
- Version control = track changes to code over time, see who changed what, and roll back
- Underlying technology: **Git**
- Git repos can be local (your computer) or synced to a **central online repository**
- Benefits of a central repo:
  - Collaborate across hundreds/thousands of developers
  - Code is backed up in the cloud (not just one machine)
  - Auditable: who committed what line, when
  - Rollback support

### 2. What is CodeCommit?
- **Private Git repository hosted on AWS**
- Developers push/pull code just like any other Git repo
- Code lives within your **VPC on the AWS cloud**
- No size limit on repositories
- Fully managed, highly available
- Increased security & compliance (code never leaves AWS)

### 3. Security Model
| Layer | Mechanism |
|---|---|
| Authentication | SSH keys or HTTPS (username/password) |
| Authorization | IAM policies (users & roles per repo) |
| Encryption at rest | AWS KMS |
| Encryption in transit | HTTPS or SSH protocols |
| Cross-account access | IAM Role + STS `AssumeRole` API (never share SSH keys/credentials) |

### 4. Integrations
- Works with standard Git CLI
- Integrates with **CodeBuild**, **Jenkins**, and other CI tools
- Native AWS service → single IAM plane for security management

### 5. CodeCommit vs GitHub
| Feature | CodeCommit | GitHub |
|---|---|---|
| Code reviews / PRs | ✅ | ✅ |
| CodeBuild integration | ✅ | ✅ |
| SSL / HTTPS auth | ✅ | ✅ |
| Auth model | IAM users & roles | GitHub users / SSO (Enterprise) |
| Hosting | AWS cloud only | GitHub.com or self-hosted (Enterprise) |
| UI | Minimal | Fully featured |

## Exam Tips
- CodeCommit = private Git repo on AWS, fully managed
- Authentication: **SSH keys** or **HTTPS**
- Authorization: **IAM policies**
- Encryption at rest: **KMS**; in transit: HTTPS/SSH
- Cross-account access → **IAM Role + STS AssumeRole** (never share credentials)
- Code stays within AWS (VPC) → compliance/security requirement
