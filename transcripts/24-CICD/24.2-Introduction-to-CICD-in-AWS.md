# 24.2 - Introduction to CICD in AWS

**Section:** 24 — AWS CICD: CodeCommit, CodePipeline, CodeBuild, CodeDeploy

## Key Concepts

### Why CICD?
Manual deployments are slow and error-prone. CICD automates the full path from code push to production:
- Code tested automatically before deploy
- Deploy to multiple stages (dev → test → staging → prod)
- Optional manual approvals before prod
- Result: more speed, more safety, happier developers

---

### CI — Continuous Integration
Developers push code often to a central repo → build server tests it automatically → fast feedback.

- **Code repos:** CodeCommit (AWS), GitHub, Bitbucket
- **Build/test servers:** CodeBuild (AWS), Jenkins CI
- **Benefits:** catch bugs early, no manual testing on dev machine, faster delivery

### CD — Continuous Delivery
Every passing build is automatically deployed to application servers.

- Shift from "one release every 3 months" → "up to 5 releases/day"
- **Deployment tools:** CodeDeploy (AWS), Jenkins CD, Spinnaker

---

### AWS CICD Services Overview

| Service | Role | Alternatives |
|---|---|---|
| **CodeCommit** | Git repository (source) | GitHub, Bitbucket |
| **CodeBuild** | Build + test | Jenkins CI |
| **CodeDeploy** | Deploy to EC2, on-prem, Lambda, ECS | Elastic Beanstalk |
| **CodePipeline** | Orchestrates the whole pipeline | — |
| **CodeStar** | All-in-one dashboard (CodeCommit + Pipeline + Build + Deploy) | — |
| **CodeArtifact** | Store, publish, share software packages | — |
| **CodeGuru** | Automated code reviews via ML | — |

### Pipeline Flow

```
Code Repo          Build & Test       Deploy
(CodeCommit   →    CodeBuild      →   CodeDeploy    →  EC2 / Lambda / ECS
 GitHub             Jenkins CI)        Beanstalk)
 Bitbucket)
              ←──────────────────────────────────────
                     Orchestrated by CodePipeline
```

---

## Exam Tips
- CI = push code → test automatically → fast feedback
- CD = every green build → automatically deployed
- CodePipeline **orchestrates** — it doesn't build or deploy itself
- CodeDeploy targets: EC2, on-premises, Lambda, ECS
- Beanstalk is an alternative to CodeDeploy (also provisions infrastructure)
