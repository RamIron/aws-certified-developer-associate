# 31.11 - AWS AppConfig - Overview

## What is AppConfig?

Deploy **dynamic configuration** to your applications **without deploying new code or restarting the app**.

Configuration lives outside the app — your app polls for changes and picks them up automatically.

## Key Use Cases

- **Feature flags** — deploy a feature disabled, then enable it via AppConfig when ready
- **Fine-tune app performance** — change config parameters dynamically
- **IP block/allow lists** — update in real time without code changes

## Supported Targets

EC2, Lambda, ECS, EKS, and more.

## Config Sources

- SSM Parameter Store
- SSM Documents
- S3 buckets

## Deployment & Safety

- **Gradual rollout** — deploy config change to a subset of instances first
- **CloudWatch monitoring** — if an alarm triggers during rollout → automatic **rollback**

## Config Validation

| Method | When to use |
|---|---|
| **JSON Schema** | Validate types, required fields, format |
| **Lambda function** | Complex validation logic |

## Exam Tip 🎯

- "Dynamic config without redeploying app code" → **AppConfig**
- "Feature flags" → **AppConfig**
- Config validation: JSON Schema (simple) or Lambda (complex)
