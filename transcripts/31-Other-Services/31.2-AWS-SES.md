# 31.2 - AWS SES (Simple Email Service)

## What is SES?

AWS SES (Simple Email Service) is a cloud-based email sending and receiving service.

## Key Facts

| Feature | Detail |
|---|---|
| Send emails via | SMTP interface or AWS SDK |
| Receive emails | Yes — can trigger S3, SNS, or Lambda |
| Permissions | IAM permissions required |

## Exam Tip 🎯

- **SES = Email**. If a question mentions email (send or receive), SES is the answer.
- Questions sometimes try to trick you into using SES for non-email scenarios — don't fall for it.
