# 31.4 - Amazon Athena - Overview

## What is Athena?

- **Serverless** query service to analyze data stored in **Amazon S3**
- Uses **standard SQL** (built on the **Presto** engine)
- No database to provision — serverless
- Pricing: **fixed amount per TB of data scanned**

## Supported Formats

CSV, JSON, ORC, Avro, **Parquet** (recommended)

## Common Use Cases

- Ad hoc queries
- Business intelligence / analytics / reporting
- Analyzing AWS logs: VPC Flow Logs, Load Balancer logs, CloudTrail, etc.

## Common Integration

**Athena + Amazon QuickSight** → reports and dashboards on top of S3 data

---

## Performance Improvements (Exam Focus)

| Technique | How | Why |
|---|---|---|
| **Columnar format** | Use Apache Parquet or ORC | Scan only the columns you need → less data scanned → lower cost |
| **Compression** | GZIP, Snappy, etc. | Smaller files → faster retrieval |
| **Partitioning** | Organize S3 paths by column values (e.g. `/year=1991/month=1/day=1`) | Athena knows exactly which folder to scan |
| **Large files** | Use files ≥ 128 MB | Fewer files = less overhead |

> **Convert to Parquet/ORC:** use **AWS Glue** as an ETL job (e.g. CSV → Parquet)

### Partitioning Example

```
s3://my-bucket/flight-data/year=1991/month=01/day=01/data.parquet
```
When you filter by year + month + day, Athena goes directly to that folder.

## Federated Query

- Athena can query data **outside of S3**: RDS, DynamoDB, ElastiCache, DocumentDB, Redshift, Aurora, SQL Server, MySQL, HBase on EMR, on-premises databases
- Uses a **Data Source Connector** = a **Lambda function** per data source
- Results can be stored back to **S3** for later analysis

```
Athena → Lambda (Data Source Connector) → RDS / DynamoDB / ElastiCache / etc.
                                          Results → S3
```

---

## Exam Tips 🎯

- **Serverless SQL on S3** → Athena
- **Best formats** for performance/cost: **Parquet** and **ORC**
- **Convert to Parquet/ORC** → use **Glue ETL**
- **Federated Query** = Lambda function as connector to non-S3 sources
- Athena + QuickSight = BI/dashboards on S3
