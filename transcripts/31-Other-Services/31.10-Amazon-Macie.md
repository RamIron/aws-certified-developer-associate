# 31.10 - Amazon Macie

## What is Macie?

Fully managed **data security and privacy service** that uses **machine learning** to discover and protect sensitive data in AWS — specifically **PII (Personally Identifiable Information)** in S3 buckets.

## How it works

```
S3 Buckets → Macie (ML pattern matching) → discovers PII → EventBridge → SNS / Lambda / etc.
```

## Key Facts

- Analyzes **S3 buckets** only
- Detects **PII** and other sensitive data
- Notifies via **EventBridge**
- One-click to enable — just specify the S3 buckets

## Exam Tip 🎯

- "Discover sensitive data / PII in S3" → **Macie**
