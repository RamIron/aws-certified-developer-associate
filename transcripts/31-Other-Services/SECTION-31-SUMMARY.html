Amazon OpenSearch Service Amazon OpenSearch Service

Amazon OpenSearch (formerly ElasticSearch, renamed due to licensing) lets you query any field, including partial matches. Unlike DynamoDB which only queries by primary key or indexes, OpenSearch is used as a complement to another database, not a replacement. Amazon OpenSearch (antes ElasticSearch, renombrado por licencias) permite consultar cualquier campo, incluyendo coincidencias parciales. A diferencia de DynamoDB que solo consulta por clave primaria o indices, se usa como complemento, no reemplazo.

Amazon MSK - Managed Streaming for Apache Kafka Amazon MSK - Managed Streaming for Apache Kafka

MSK is a fully managed Apache Kafka service on AWS. Kafka is an alternative to Amazon Kinesis for streaming data. MSK handles broker nodes, Zookeeper nodes, failure recovery, and deploys across multiple AZs in your VPC. Data is stored on EBS volumes and can be retained as long as you want. MSK Serverless removes the need to provision or manage capacity entirely. MSK es un servicio Kafka completamente administrado en AWS. Kafka es una alternativa a Amazon Kinesis para streaming de datos. MSK maneja broker nodes, Zookeeper nodes, recuperacion de fallos y se despliega en multiples AZs en tu VPC. Los datos se guardan en EBS y se pueden retener todo el tiempo que quieras. MSK Serverless elimina la necesidad de provisionar capacidad.

ACM provisions, manages, and deploys SSL/TLS certificates to provide in-flight encryption via HTTPS endpoints. Public TLS certificates are free and renew automatically. ACM integrates directly with ELB, CloudFront, and API Gateway — you never need to handle the certificate manually. ACM provisiona, administra y despliega certificados SSL/TLS para proveer cifrado en transito via HTTPS. Los certificados TLS publicos son gratuitos y se renuevan automaticamente. Amazon Macie Amazon Macie

Macie is a fully managed data security service that uses machine learning to discover and protect sensitive data — specifically PII (Personally Identifiable Information) — in your S3 buckets. It notifies via EventBridge, which can trigger SNS, Lambda, and more. One click to enable. Macie es un servicio de seguridad de datos que usa machine learning para descubrir y proteger datos sensibles — especificamente PII (informacion de identificacion personal) — en tus buckets S3. Notifica via EventBridge, que puede disparar SNS, Lambda, etc. Un clic para activar.

How it worksComo funciona

Macie scans S3 buckets, identifies PII using ML pattern matching, and sends findings to EventBridge for downstream processing.Macie escanea buckets S3, identifica PII con ML y envia los hallazgos a EventBridge para procesamiento posterior.

⭐ Exam trigger:Trigger del examen: "discover PII / sensitive data in S3""descubrir PII / datos sensibles en S3" → Macie

AWS AppConfig AWS AppConfig

AppConfig lets you deploy dynamic configuration to your applications without deploying new code or restarting the app. Your app polls AppConfig for changes and picks them up automatically. Classic use case: feature flags — ship a feature disabled, then enable it via AppConfig when ready, with no redeploy. AppConfig permite desplegar configuracion dinamica a tus apps sin desplegar nuevo codigo ni reiniciar la app. Tu app consulta AppConfig periodicamente y toma los cambios automaticamente. Caso tipico: feature flags — desplegás una feature desactivada y la activás desde AppConfig cuando estás listo, sin redeploy.
