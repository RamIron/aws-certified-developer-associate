# 31.7 - Amazon Certificate Manager (ACM)

## What is ACM?

Provision, manage, and deploy **SSL/TLS certificates** for in-flight encryption (HTTPS endpoints).

## Key Facts

| Feature | Detail |
|---|---|
| Purpose | Provision & deploy TLS certificates |
| Certificate types | Public and Private TLS |
| Cost | **Free** for public TLS certificates |
| Renewal | **Automatic** TLS certificate renewal |
| Integrations | ELB, CloudFront, API Gateway |

## Typical Architecture

```
Client → HTTPS → ALB (TLS cert loaded from ACM) → HTTP → EC2 (Auto Scaling Group)
```

## Exam Tip 🎯

- "In-flight encryption", "HTTPS endpoint", "SSL/TLS certificate" → **ACM**
