# 31.5 - Amazon Athena - Hands On

## What was demonstrated

- Launched Athena Query Editor in the AWS console
- Configured an S3 bucket as the query result location
- Queried S3 Access Logs using Athena:
  1. Created a database (`s3_access_logs_db`)
  2. Created a table using a query from AWS documentation (only needed to change the S3 bucket location + trailing slash)
  3. Previewed 10 rows from the table
  4. Ran aggregation queries: count requests by HTTP status and request URI
  5. Ran a specific query filtering for 403 (unauthorized) responses

## Key takeaways

- Athena query results are stored in a separate S3 bucket (required setup before first query)
- Table schema comes from AWS documentation — just change the bucket location
- S3 prefix matters: if data is in a subfolder, include it in the location path (with trailing slash)
- No servers, no clusters — just SQL against S3 data
