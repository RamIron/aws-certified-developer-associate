# 28.9 - AppSync Overview

## What is AppSync?

AppSync is a managed AWS service for building **GraphQL APIs**. It sits in the middle between clients and data sources, resolving queries automatically.

---

## Two exam angles

### 1. Managed GraphQL API
- Upload a GraphQL schema → AppSync resolves queries against your data sources
- Direct integrations: **DynamoDB, Aurora, OpenSearch**
- Extend with **Lambda** for any other source
- HTTP integration for existing public HTTP endpoints

### 2. Real-time / Offline sync
- **WebSocket** or **MQTT on WebSocket** for real-time subscriptions
- Offline data sync for mobile apps (replaces the deprecated **Cognito Sync**)
- Use cases: real-time dashboards, collaborative apps, offline-first mobile

---

## How it works

```
Client sends GraphQL query
         │
         ▼
     AppSync (GraphQL schema + resolvers)
         │
    ┌────┼────┬────────────┐
    ▼    ▼    ▼            ▼
DynamoDB Aurora OpenSearch Lambda / HTTP
```

The client specifies exactly which fields it wants. AppSync runs the resolver, fetches only that data, and returns it as JSON.

## Data Sources (Resolvers)

| Source | Notes |
|---|---|
| DynamoDB | Direct integration |
| Aurora | Direct integration |
| OpenSearch | Direct integration |
| Lambda | Any source — full flexibility |
| HTTP endpoints | Existing public APIs |

---

## Security — 4 Authorization Modes

| Mode | Description |
|---|---|
| `API_KEY` | Generate keys and distribute to users (like API Gateway) |
| `AWS_IAM` | IAM users, roles, cross-account access |
| `OPENID_CONNECT` | OpenID Connect provider + JWT |
| `AMAZON_COGNITO_USER_POOLS` | Cognito User Pools (supports social login federation) |

---

## Observability & HTTPS

- **CloudWatch Metrics + Logs** for monitoring
- **Custom domain + HTTPS** → put **CloudFront in front of AppSync**

---

## Exam Tips

- ✅ AppSync = **managed GraphQL API** on AWS
- ✅ Real-time → **WebSocket** or **MQTT on WebSocket**
- ✅ Offline mobile sync → AppSync **replaces Cognito Sync**
- ✅ Direct integrations: DynamoDB, Aurora, OpenSearch + Lambda for anything else
- ✅ 4 auth modes: API_KEY, AWS_IAM, OPENID_CONNECT, AMAZON_COGNITO_USER_POOLS
- ✅ HTTPS with custom domain → **CloudFront in front of AppSync**
