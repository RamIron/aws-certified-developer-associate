## What was demonstrated

- Created a GraphQL API ("My AppSync API") backed by a **DynamoDB table** (StudentTable)
- Schema auto-generated from a model: `Student { id: ID!, name: String!, age: Int, certified: Boolean }`
- Ran `createStudent` mutations (Mike, Alice) and `listStudents` query → data visible in both AppSync and DynamoDB
- Confirmed 4 authorization modes in settings: API Key, IAM, OpenID Connect, Lambda, Cognito User Pools
- Custom domain names option visible in settings

## Key takeaways for the exam

- You upload a GraphQL **schema** → AppSync auto-creates resolvers + DynamoDB table
- The GraphQL **endpoint** and **API ID** are shown in settings
- Multiple authorization providers can be active simultaneously
