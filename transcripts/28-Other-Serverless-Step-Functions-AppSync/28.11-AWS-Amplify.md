# 28.11 - AWS Amplify

## What is Amplify?

AWS Amplify = **"Elastic Beanstalk for mobile and web applications"**

A set of tools and services to build, ship, and host full-stack apps without managing infrastructure manually.

---

## The 4 Components

| Component | What it is |
|---|---|
| **Amplify Studio** | Visual interface to build frontend UI and backend resources |
| **Amplify CLI** | Command-line toolchain (`amplify init`, `amplify add auth`, etc.) |
| **Amplify Libraries** | Client-side libraries for React, Vue, JS, iOS, Android, Flutter |
| **Amplify Hosting** | CI/CD + CDN hosting (like Netlify / Vercel) |

---

## Backend Services (auto-provisioned)

- **Auth** → Cognito (MFA, social sign-in, pre-built UI components)
- **DataStore** → AppSync + DynamoDB (offline + real-time sync, GraphQL)
- **Storage** → S3
- Plus: Lambda, API Gateway, etc.

---

## Feature 1 — Authentication

```
amplify add auth
```

- Leverages **Cognito** under the hood
- Supports MFA, social sign-in (Google, Facebook, etc.)
- Pre-built UI components for login/signup screens
- Works across React, Vue, iOS, Android, Flutter

---

## Feature 2 — DataStore

```
amplify add api
```

- Uses **AppSync (GraphQL) + DynamoDB** under the hood
- Writes to **local data** first (offline), syncs to cloud when online
- Powered by GraphQL schema → auto-generates resolvers
- Provides **real-time** subscriptions via WebSocket

---

## Feature 3 — Hosting

```
amplify add hosting
```

- Connect Git repo (GitHub, GitLab, Bitbucket, **CodeCommit**)
- Build frontend → deploy to **CloudFront**
- Features: PR previews, custom domains, monitoring

### CI/CD Flow

```
Git push (GitHub / GitLab / Bitbucket / CodeCommit)
        │
        ▼
  Amplify build (amplify.yml)
        │
        ▼
  Deploy to CloudFront (CDN)
```

---

## Testing in amplify.yml

Defined in `amplify.yml`:

1. **Unit tests** → run at build time
2. **End-to-end tests** → **Cypress** framework
   - Simulates real browser clicks
   - Generates UI test report
   - If tests fail → deploy is blocked
