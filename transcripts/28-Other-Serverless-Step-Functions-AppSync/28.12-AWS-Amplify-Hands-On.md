# 28.12 - AWS Amplify Hands On

> **Skipped** — hands-on walkthrough. Key observations noted below.

## What was demonstrated

- Cloned the Amplify VT React template (to-do app) to GitHub
- Connected GitHub repo to Amplify → authorized AWS Amplify console to read repo
- Amplify bootstrapped the account via **CDK** (CDK Toolkit stack created in CloudFormation)
- Build completed → app deployed to a CloudFront domain (fully working to-do app)
- CloudFormation shows 1 parent Amplify stack + 4 nested stacks (full infra managed by CDK)

## Amplify Console features shown

- **Data Manager** → view/edit/create records directly (backed by DynamoDB table)
- **User Management** → create users; deep integration with Amazon Cognito
- **Storage** → configure S3-backed storage
- **Functions** → Lambda functions abstracted through Amplify
- **UI Library** → pre-built components + Figma-to-React integration
- **Custom domains, build notifications, build settings, environment variables**

## Key takeaways for the exam

- Amplify uses **CDK under the hood** to provision all infrastructure
- All resources visible in **CloudFormation** as nested stacks
- Data is stored in **DynamoDB** (visible from Data Manager AND directly in DynamoDB console)
- Deleting the Amplify app cleans up all provisioned resources automatically
- Comparable to **Netlify/Vercel** but everything stays in your AWS account (private)
