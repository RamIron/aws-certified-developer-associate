# 30.5 — KMS Envelope Encryption & Key APIs

## The Problem: 4 KB Limit

The KMS `Encrypt` API only supports up to **4 KB of data**.  
For larger data → use **Envelope Encryption**.

> ⭐ Exam rule: anything over 4 KB → use `GenerateDataKey` API (envelope encryption)

---

## Envelope Encryption — Encrypt Flow

```
SDK calls GenerateDataKey(CMK)
        ↓
KMS checks IAM → returns:
  - Plaintext DEK (Data Encryption Key)
  - Encrypted DEK (encrypted by the CMK)
        ↓
Client encrypts BIG FILE using Plaintext DEK (client CPU, no KMS involved)
        ↓
Final envelope file = { Encrypted DEK + Encrypted Big File }
        ↓
Store the envelope file (S3, disk, etc.)
Discard Plaintext DEK — never store it
```

## Envelope Encryption — Decrypt Flow

```
Load envelope file → extract Encrypted DEK + Encrypted File
        ↓
Call KMS Decrypt(Encrypted DEK) → returns Plaintext DEK
        ↓
Client decrypts Encrypted File using Plaintext DEK
        ↓
Decrypted Big File ✅
```

---

## AWS Encryption SDK

AWS provides a ready-made SDK that implements envelope encryption for you.  
Available for Java, Python, C, JavaScript. Also a CLI tool.

### Data Key Caching
- Reuse the same DEK for multiple files instead of calling `GenerateDataKey` every time
- **Fewer API calls → lower cost**
- **Trade-off: lower security** (same key used for many files)
- Configured with `LocalCryptoMaterialsCache`:
  - `maxAge` — max time to reuse a key
  - `maxBytesEncrypted` — max bytes before rotating
  - `maxMessagesEncrypted` — max messages before rotating

## KMS Symmetric APIs — Exam Cheatsheet

| API | What it does | When to use |
|---|---|---|
| `Encrypt` | Encrypts up to 4 KB with CMK | Small secrets |
| `Decrypt` | Decrypts up to 4 KB | Decrypt small secrets or DEK |
| `GenerateDataKey` | Returns **plaintext DEK + encrypted DEK** | Envelope encryption **right now** |
| `GenerateDataKeyWithoutPlaintext` | Returns **only encrypted DEK** | Generate for later use — must decrypt first before using |
| `GenerateRandom` | Returns random byte string | Random number generation |

> ⭐ Exam trap: `GenerateDataKey` vs `GenerateDataKeyWithoutPlaintext`  
> → If you need to encrypt now: `GenerateDataKey`  
> → If storing for later: `GenerateDataKeyWithoutPlaintext`
