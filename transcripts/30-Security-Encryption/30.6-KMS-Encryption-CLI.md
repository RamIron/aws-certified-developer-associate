# 30.6 — KMS Encryption CLI (Hands-On)

## AWS Encryption CLI

Not required for the exam — this is purely practical to see envelope encryption in action.

### Install
```bash
pip install aws-encryption-sdk-cli
aws-encryption-cli --version
```

### Encrypt a file (envelope encryption under the hood)
```bash
export KEY=arn:aws:kms:eu-west-2:ACCOUNT_ID:key/KEY_ID

aws-encryption-cli --encrypt \
  --input hello.txt \
  --master-keys key=$KEY \
  --output output/ \
  --metadata-output metadata/
```

### Decrypt
```bash
aws-encryption-cli --decrypt \
  --input output/hello.txt.encrypted \
  --output decrypted/ \
  --metadata-output metadata/
```

## What happens under the hood
- The CLI calls `GenerateDataKey` on the CMK
- Encrypts the file locally (client CPU — not KMS)
- Stores the encrypted DEK alongside the encrypted data in the output file
- On decrypt: reads the encrypted DEK from the file, calls KMS `Decrypt`, then decrypts locally

## Key notes
- The metadata file contains: algorithm used, data key info, encryption context
- Metadata is optional — the important output is the encrypted file
- Works for arbitrarily large files (no 4 KB limit)
