# 30.1 — Section Introduction: AWS Security & Encryption

## Overview

This is one of the most important sections for the DVA-C02 exam. It consolidates all security concepts seen throughout the course and adds dedicated deep dives on:

- KMS (Key Management Service)
- Encryption SDK / Envelope Encryption
- SSM Parameter Store
- Secrets Manager
- CloudHSM
- CloudWatch Logs Encryption
- CodeBuild Security
- Nitro Enclaves

## Key Point

> "Anytime you hear encryption in an AWS service, it's most likely going to be KMS encryption."

This section is real-world oriented and includes hands-on with AWS Lambda.
