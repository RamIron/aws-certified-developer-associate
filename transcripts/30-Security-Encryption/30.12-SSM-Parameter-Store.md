# 30.12 — SSM Parameter Store

## What is it?

Secure storage for **configuration and secrets** — part of AWS Systems Manager.

- Optional KMS encryption (makes it a "SecureString")
- Serverless, scalable, durable
- Version tracking on every update
- IAM-based access control
- EventBridge notifications on parameter changes
- Native CloudFormation integration

## Storage Hierarchy

Parameters are organized in a path-like hierarchy:

```
/my-app/dev/db-url
/my-app/dev/db-password
/my-app/prod/db-url
/my-app/prod/db-password
/other-app/dev/api-key
```

Benefits:
- IAM policies can target `/my-app/dev/*` to restrict by environment
- `GetParametersByPath` retrieves all params under a path recursively

## Parameter Tiers

| Feature | Standard | Advanced |
|---|---|---|
| Max size | 4 KB | 8 KB |
| Parameter policies (TTL) | No | Yes |
| Cost | Free | $0.05 per parameter/month |
| Cross-account sharing | No | Yes |
| Max count | 10,000 | 100,000 |

## Parameter Types

| Type | Use case |
|---|---|
| `String` | Plain text config (URLs, names, etc.) |
| `StringList` | Comma-separated values |
| `SecureString` | Secrets — encrypted with KMS |

## Parameter Policies (Advanced only)

Assign a **TTL (expiration)** to force rotation of sensitive values:
- `Expiration` — delete parameter on a specific date
- EventBridge gets notified N days before expiration (e.g. 15 days)
- `NoChangeNotification` — alert if a param hasn't been updated in N days

## Useful Trick

You can pull a secret from **Secrets Manager** using the Parameter Store API:
```
/aws/reference/secretsmanager/my-secret
```

## Public Parameters (AWS-provided)

AWS publishes parameters like the latest AMI ID for Amazon Linux 2:
```bash
aws ssm get-parameters --names /aws/service/ami-amazon-linux-latest/amzn2-ami-hvm-x86_64-gp2
```

## CLI Commands

```bash
# Get specific parameters
aws ssm get-parameters --names /my-app/dev/db-url /my-app/dev/db-password

# With decryption for SecureString
aws ssm get-parameters --names /my-app/dev/db-password --with-decryption

# Get all params under a path
aws ssm get-parameters-by-path --path /my-app/dev

# Recursive (includes sub-paths)
aws ssm get-parameters-by-path --path /my-app --recursive --with-decryption
```
