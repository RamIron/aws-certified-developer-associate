# 30.16 — SSM Parameter Store vs Secrets Manager

## Quick Comparison

| Feature | Secrets Manager | SSM Parameter Store |
|---|---|---|
| Cost | $0.40/secret/month + $0.05/10k API calls | Free (standard) |
| KMS encryption | **Mandatory** | Optional |
| Native secret rotation | ✅ via Lambda (AWS-provided for RDS/Redshift/DocDB) | ❌ must DIY with EventBridge + Lambda |
| RDS/Aurora/Redshift integration | ✅ Deep | ❌ Manual |
| Value structure | Key-value pairs (JSON) | Single string |
| CloudFormation integration | ✅ | ✅ |
| Pull from SSM Parameter Store API | ✅ (via `/aws/reference/secretsmanager/` path) | N/A |

## Rotation Pattern — Secrets Manager (native)

```
Secrets Manager → (every 30 days) → Lambda (AWS-provided for RDS)
                                         ↓
                                   RDS: new password set
                                   Secrets Manager: updated ✅
```

## Rotation Pattern — Parameter Store (manual)

```
EventBridge Rule (schedule: every 30 days)
        ↓
Lambda function (you write it)
        ↓
  ├── Update RDS password
  └── Update /my-app/prod/db-password in Parameter Store
```

## Exam Decision Rule

- **RDS/Aurora credentials + auto-rotation** → Secrets Manager
- **App config + optional encryption + free** → SSM Parameter Store
- **Mandatory KMS** → Secrets Manager
- **TTL/expiration on params** → SSM Parameter Store Advanced tier
