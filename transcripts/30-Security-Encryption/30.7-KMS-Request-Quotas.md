# 30.7 — KMS Request Quotas

## ThrottlingException

When you exceed KMS request quotas you get:
```
Status Code: 400; Error Code: ThrottlingException
```

## Shared Quota

All cryptographic operations share a **single quota per account per region**:
`Encrypt`, `Decrypt`, `GenerateDataKey`, `GenerateRandom`, etc.

This includes calls made **on your behalf** by AWS services (e.g. S3 with SSE-KMS encrypting every object).

### Quota values (varies by region)
| Region type | Symmetric CMK quota |
|---|---|
| Standard | 5,500 req/sec |
| Some regions | 10,000 req/sec |
| Other regions | 30,000 req/sec |

## Solutions

| Solution | When to use |
|---|---|
| **Exponential backoff** | Transient throttling — retry with increasing delays |
| **DEK caching** (Encryption SDK `LocalCryptoMaterialsCache`) | Reduce calls by reusing data keys for multiple files |
| **Request a quota increase** | Persistent throttling — open a ticket with AWS Support or via API |

## Exam Tip
> ⭐ Three ways to deal with KMS throttling: exponential backoff → DEK caching → quota increase request
