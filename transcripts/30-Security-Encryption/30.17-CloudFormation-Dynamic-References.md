# 30.17 — CloudFormation Dynamic References

## What is it?

CloudFormation can **resolve values from SSM Parameter Store or Secrets Manager at deploy time** using dynamic references.

Supports: create, update, delete stack operations.

## Syntax

```
{{resolve:service-name:reference-key}}
```

## Three Types

| Reference | Source | Use case |
|---|---|---|
| `{{resolve:ssm:parameter-name:version}}` | SSM Parameter Store (plaintext) | Non-sensitive config |
| `{{resolve:ssm-secure:parameter-name:version}}` | SSM Parameter Store (SecureString) | Encrypted secrets in SSM |
| `{{resolve:secretsmanager:secret-id:secret-string:json-key:version-stage:version-id}}` | Secrets Manager | DB passwords, API keys |

## Examples

```yaml
# S3 bucket ACL from SSM plaintext
Type: AWS::S3::Bucket
Properties:
  AccessControl: "{{resolve:ssm:/my-app/bucket-acl:1}}"

# IAM User password from SSM SecureString
Type: AWS::IAM::User
Properties:
  LoginProfile:
    Password: "{{resolve:ssm-secure:/my-app/user-password:1}}"

# RDS master password from Secrets Manager
Type: AWS::RDS::DBInstance
Properties:
  MasterUsername: "{{resolve:secretsmanager:prod/db:SecretString:username}}"
  MasterUserPassword: "{{resolve:secretsmanager:prod/db:SecretString:password}}"
```

## RDS + Secrets Manager in CloudFormation — Two Patterns

### Pattern 1: RDS Manages the Secret (implicit)
```yaml
# CloudFormation creates RDS → RDS creates secret in Secrets Manager automatically
Type: AWS::RDS::DBCluster
Properties:
  ManageMasterUserPassword: true   # RDS creates & manages the secret

# To get the secret ARN in outputs:
Outputs:
  SecretArn:
    Value: !GetAtt MyDB.MasterUserSecret.SecretArn
```

### Pattern 2: CloudFormation Manages the Secret (explicit)
```yaml
# 1. Create secret (auto-generates password)
MySecret:
  Type: AWS::SecretsManager::Secret
  Properties:
    GenerateSecretString:
      SecretStringTemplate: '{"username": "admin"}'
      GenerateStringKey: "password"

# 2. RDS uses the secret via dynamic reference
MyDB:
  Type: AWS::RDS::DBInstance
  Properties:
    MasterUsername: "{{resolve:secretsmanager:MySecret:SecretString:username}}"
    MasterUserPassword: "{{resolve:secretsmanager:MySecret:SecretString:password}}"

# 3. Link secret to DB for rotation
MySecretAttachment:
  Type: AWS::SecretsManager::SecretTargetAttachment
  Properties:
    SecretId: !Ref MySecret
    TargetId: !Ref MyDB
    TargetType: AWS::RDS::DBInstance
```

## Exam Tip
> `{{resolve:ssm:...}}` = plaintext SSM  
> `{{resolve:ssm-secure:...}}` = encrypted SSM SecureString  
> `{{resolve:secretsmanager:...}}` = Secrets Manager  
> `ManageMasterUserPassword: true` = RDS creates/manages its own secret
