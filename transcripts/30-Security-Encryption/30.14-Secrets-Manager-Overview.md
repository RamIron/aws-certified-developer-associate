# 30.14 — AWS Secrets Manager Overview

## What is it?

A **newer, purpose-built secret storage service** focused on lifecycle management of secrets.

Key differentiator vs SSM Parameter Store:
> Secrets Manager has **native automatic secret rotation** powered by Lambda.

## Features

- Force rotation every X days (configurable up to 1 year)
- Automated rotation via Lambda (AWS provides functions for RDS, Redshift, DocumentDB out of the box)
- Deep integration with RDS, Aurora, Redshift, DocumentDB — stores DB credentials and can update the DB password automatically
- **KMS encryption is mandatory** (not optional like in Parameter Store)
- Stores key-value pairs (multiple keys per secret)
- CloudFormation integration

## Pricing

- **$0.40 per secret per month**
- **$0.05 per 10,000 API calls**
- **30-day free trial** for the service (starts when you store your first secret)

## Multi-Region Secrets

- Replicate a secret to multiple AWS regions
- Secrets Manager keeps replica in sync with the primary
- Use cases:
  - Disaster recovery (promote replica to standalone if primary region fails)
  - Multi-region apps reading from local region
  - Cross-region RDS replication (same secret in both regions)

## Exam Tip

| Trigger | Think |
|---|---|
| RDS credential management | Secrets Manager |
| Automatic secret rotation | Secrets Manager |
| Integration with Aurora/RDS password | Secrets Manager |
| Secret + KMS mandatory | Secrets Manager |
| Cheaper option, no rotation needed | SSM Parameter Store SecureString |
