# 30.19 — CodeBuild Security

## Two Security Concerns

### 1. Network Access
- CodeBuild runs outside your VPC by default
- To access VPC resources (RDS, ElastiCache, internal services), launch CodeBuild **inside your VPC**
- Configure: subnets + security groups in the CodeBuild project settings

### 2. Secrets in Environment Variables

❌ **Never do this:**
```
DB_PASSWORD = supersecret   (plaintext env var)
```

✅ **Do this instead — reference from SSM Parameter Store:**
```
DB_PASSWORD → type: Parameter → value: /CodeBuild/DBPassword
```

✅ **Or reference from Secrets Manager:**
```
DB_PASSWORD → type: Secrets Manager → value: prod/my-db/password
```

At build time, CodeBuild fetches the actual value automatically.

## How to Set Up in Console

CodeBuild → Create build project → Additional configuration → Environment variables:
- Name: `DB_PASSWORD`
- Value: `/CodeBuild/DBPassword`
- Type: **Parameter** (SSM) or **Secrets Manager**

## IAM Requirements

The CodeBuild service role must have permissions to read from whichever service you use:
- SSM: `ssm:GetParameters` on the parameter ARN
- Secrets Manager: `secretsmanager:GetSecretValue` on the secret ARN
- If SecureString in SSM: also `kms:Decrypt` on the KMS key ARN

## Exam Pattern
> CodeBuild + secrets → SSM Parameter Store or Secrets Manager reference in env vars  
> CodeBuild + VPC resources → launch CodeBuild inside the VPC
