# 30.2 — Encryption 101

## Three Types of Encryption

### 1. Encryption in Flight (TLS/SSL)
- Data is encrypted **before sending** and decrypted **after receiving**
- Uses **TLS certificates** (HTTPS)
- Protects against **man-in-the-middle attacks**
- Only the target server can decrypt the data

```
Client ──[TLS encrypt]──► [Network] ──► Server [TLS decrypt]
         No middle server can read the data
```

### 2. Server-Side Encryption at Rest
- Data is encrypted **after being received** by the server
- Data is decrypted **before being sent back** to the client
- A **data key** is stored and managed by the server
- Example: S3 with SSE — the object is encrypted/decrypted on the S3 side

```
Client ──HTTP/S──► S3 [encrypt with data key] ──► Stored encrypted
Client ◄──HTTPS── S3 [decrypt with data key] ◄── Stored encrypted
```

### 3. Client-Side Encryption
- Data is encrypted **by the client** before sending
- The server **never** sees the decrypted data (we don't trust the server)
- The client holds the data key
- Can store in S3, EBS, FTP, etc. — all stored encrypted

```
Client [encrypt with client key] ──► S3 (stores encrypted blob, can't read it)
Client [decrypt with client key] ◄── S3 (returns encrypted blob)
```

## Exam Tip

| Type | Where encryption happens | Who holds the key |
|---|---|---|
| In flight (TLS) | In transit | TLS certificate infrastructure |
| Server-side at rest | On the server | Server (AWS service) |
| Client-side | On the client | Client only |
